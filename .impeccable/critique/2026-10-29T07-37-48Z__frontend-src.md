## 实现

| 原问题 | 完成后的行为 |
| --- | --- |
| 币安监控位于两张长榜单之后 | 默认直接显示异动监控；排行榜为相邻标签，合约与现货独立切换，排序及图表入口保留 |
| 股票目录在窄屏需要横向找字段 | 搜索优先，额外筛选可展开；统计可直接筛选；窄屏按字段排成记录，平台产品仍可原位展开 |
| DCA 配置和结果缺少主次 | 桌面配置侧栏与结果并排，常用四项优先，执行时间与时区收起；结果先给指标与主收益图，另两图辅助 |
| 组合双侧栏挤压内容，任务混在长页 | 使用紧凑组合选择；目标配置、流水业绩、历史模拟、风险情景分别切换，管理、备份与回收入口保留 |
| 组合风险情景输入溢出且没有名称 | 改为逐资产、带名称的百分比输入，按钮自然换行；无持仓时说明下一步，有持仓时正常计算 |
| 研究零数据仍显示三个巨型栏 | 无列表、无资产、已选资产分别呈现；根据实际内容宽度分栏；研究内部可直接切换相邻工具，主菜单隐藏策略保留 |
| 数据健康强调库存，恢复入口不明确 | 需要处理的源优先；已就绪项折叠；补齐历史定位到有可见标签的表单，进度和结果在页面反馈 |
| 设置、行情和比较页缺少结构区分 | 设置按显示偏好、分析配置、运行信息分区；市场指标可按组筛选；Web3 热度与地址表现分开；币种比较以比值图为主 |

共享组件统一了任务标签、空态和加载占位。标签支持左右方向键、Home、End 和跟随焦点，视图切换保留已编辑的内容。动效仅用于状态反馈，并遵循减少动态效果设置。
