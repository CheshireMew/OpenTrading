用户随后明确要求删除退出功能的数据库历史数据。迁移 `024_retire_legacy_tools` 删除组合配置、流水、模拟、请求回执、研究报告、旧 Python 回测的八张专用表，并删除组合偏离规则及对应事件。这是明确的数据删除，源码归档不包含这些数据库记录，回退迁移不能恢复它们。主库行情、行情压缩归档、Signal Lab、Pine、定投和普通价格提醒不属于删除范围。

此前归档的 `research_catalog.sqlite`、`research_results.sqlite`、`heimdall.db` 已清空所有数据表并执行 VACUUM，每个文件只剩 4 KB 空库。直接删除这些文件被自动审批以“策略阻止”拒绝，因此保留空文件，不保留旧记录。
