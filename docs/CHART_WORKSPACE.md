# 图表工作台

工作台位于首页 `/`。左上角菜单仍可进入研究、历史信号、市场及设置。普通行情和回放模式均可在图表内模拟交易，订单在当前浏览器中计算。

## 行情回放与模拟交易

顶部点击“回放”，中央直接显示日历，点选日期即跳转，无需再次确认；也可直接输入日期时间，或选择在图上点击起始 K 线。直接使用当前标的和周期，日期按当前图表时区解释。起点以后的行情先隐藏，以历史 1 分钟 K 线逐根推进：1 倍速每秒推进一根，倍速控制推进频率；单步也只推进一根 1 分钟 K 线。5 分钟图经过五次更新收完一根，15 分钟图经过十五次更新收完一根。回放时间只在下一根源 K 线读入时推进，不连续走秒，不按现实时间补赶行情；指标计算和数据加载完成后再安排下一次更新。可以暂停或调整倍速，按空格键切换播放和暂停，长按不重复切换；填写输入框、操作弹窗时不会触发回放快捷键。页面隐藏及切换页面时自动暂停。

日期窗口标题栏的骰子按钮可随机开始：使用当前标的和周期，先用月线、日线定位候选，再补拉并验证起点附近的实际回放源数据，成功后跳转并自动播放。分钟数据缺缓存时只补缺口，首次最多读取 1,000 根当前周期的历史 K 线和起点后的 1,000 根分钟 K 线，后续按需续拉；完全没有缓存也不需要下载全部历史。候选确实没有分钟行情时自动换日期，必要时从最近已验证的分钟区间选择；网络失败保留候选供重试，准备失败不清空原持仓。只有日线的标的仍按日线处理，加载期间禁用重复操作。

有分钟行情的标的使用已收盘的 1 分钟数据逐步更新当前周期的开、高、低、收和成交量，不模拟分钟内逐笔价格。只有日线的数据按日线推进。行情、指标和成交只使用已回放到的数据；数据缺口或下载失败时暂停并允许重试。切换周期只重建图表，保留当前回放时间、倍速、播放或暂停状态、持仓、挂单、止盈止损及成交记录；未收盘 K 线只合成已回放到的部分，加载期间不推进模拟时间。重选起点或切换标的会重新开始本次练习，退出回放则恢复实时行情。

普通行情和回放共用原图表右键菜单，在其中加入指定价位买入／做多、卖出／做空及止盈止损操作，价格轴“＋”也打开同一套菜单；原有警报、视图、坐标轴、图表设置等操作保留。普通行情下单后显示模拟盘，跟随实时行情更新，不使用下单前 K 线影线撮合；切换周期或查看其他标的再回来，当前浏览器内的该标的模拟持仓与挂单保留。实时模拟盘按标的保留，和历史回放账户独立。

普通行情的买卖栏位于图表下方；进入回放后，播放、下单和盈亏合并到图内的紧凑悬浮面板，不再占用底部图表空间。面板默认位于主图内部靠上居中，可用左侧手柄拖动或方向键移动，窗口缩放时保持在图表范围内。日期、选 K 线、播放、单步和退出使用带提示的图标，成交记录点击列表图标展开。可直接买入／做多或卖出／做空，也可在价格轴“＋”或图表右键菜单创建限价委托。开仓输入为当前交易对报价币种的金额，例如 BTC/USDT 使用 USDT、BTC/USDC 使用 USDC；市价按成交时的当前报价、限价按指定委托价换算实际数量，并按数量步长向下取整。点击买卖或菜单下单项即直接提交，不需要再次确认；悬浮面板初始位置避开左上角图例，可随时拖到需要的位置，退出回放恢复普通交易栏。未成交委托可以拖动改价或点击“×”撤销，已成交持仓的开仓价固定。已成交的持仓框除右侧关闭按钮外，文字、数量、盈亏及空白区域均可上下拖出止盈止损线，按放置价格和仓位方向自动识别类型；也可右键指定价格添加。已有止盈止损框也可整块上下拖动或双击输入精确价格，关闭按钮只执行关闭或撤单。多单止损只需低于当前价，可以高于入场价来保护利润；空单反向。未成交委托的退出线以委托价为参照。拖动时显示预计盈亏，松手生效，Esc 取消；预览期间原价位继续有效。

普通拖拽止盈止损默认保护全部剩余仓位，松手即生效，不需要输入数量；同类型再次拖出时更新原有的整仓保护线。需要分批退出时，在图表指定价格右键或点击价格轴“＋”，直接在该价位的下单框输入价格、数量，提交限价止盈或止损平仓单，可在不同价格分别下单。数量默认填入全部剩余仓位，也可用 0%～100% 滑杆和百分比快选设置，按该标的的数量步长向下取整，手动输入与比例同步；数量始终显示普通小数，不使用科学计数法。编辑已有部分退出单时同样提供滑杆。部分成交只移除触发的退出单，其余退出线保留，整仓保护始终跟随剩余仓位，固定数量超过剩余仓位时自动缩减；全部平仓后清除其余退出单。持仓线的“×”按当前回放价格平掉剩余仓位。

本次同时保留一笔开仓委托或一个仓位，利润按数量和价格变动计算，不计算杠杆、保证金、强平、手续费或资金费率。同一历史分钟同时触及止盈和止损、无法确定先后时按止损先触发；修改后的订单不追溯使用修改前的影线。图上显示成交标记，底部显示累计利润、浮动盈亏及本次已平仓交易。记录保留到重新开始或刷新页面，不创建云端训练档案。

公开站和本地版均由浏览器负责回放、周期合成及模拟交易。历史读取使用 `/api/v1/chart-workspace/replay/bars`，复用共享 K 线存储并合并相同的并发请求；已完成历史支持 HTTP 缓存。服务器不为每位访问者运行交易任务。

同一浏览器标签页内，所有页面都保留各自已加载的内容、筛选条件、表单与结果，切回来直接显示，主内容区的滚动位置也会恢复。已有自动更新的页面仅在显示时轮询，返回时在保留内容的同时继续更新；刷新整个网页后，界面重新初始化并恢复已保存的个人数据。缓存保存在访问者浏览器中，本地版和公开站使用相同逻辑。

## 看盘与保存

顶部选择品种和周期，布局支持单图、左右双图、上下双图、四图。带边框的是活动图，自选切图、指标添加和 Pine 运行都作用于它。默认只同步十字线和时间范围，品种和周期同步在“同步”中单独开启。隐藏的图表会保留状态，重新展开时恢复。

左侧绘图工具支持趋势线、射线、水平／垂直线、平行通道、矩形、斐波那契回撤、文字、箭头、画笔和时间／价格测量。工具分组中的小箭头可展开更多工具。选中对象后可修改样式、坐标、锁定、隐藏、复制、移除；顶部撤销、重做也可用于绘图。“对象列表”管理当前图的绘图和指标，“数据窗口”显示十字线所在位置的数值。

绘图使用时间与价格坐标，并按图表、市场品种隔离。现货与永续是两个不同品种；切换周期保留锚点。图表向左拖动时按需补历史，顶部“设置”可调整首次加载的历史根数。

右侧自选支持多个列表、新建、重命名、删除、拖动排序和添加品种。每行的 × 可直接移除品种，无需先进入编辑模式。列表行情显示品种、最新价、涨跌额和涨跌幅，市场与统计口径可在品种提示中查看。右上角更多菜单管理列表；删除前会说明范围。工作台自选与“研究追踪”的观察列表独立。

拖动右侧或底部的分隔线调整面板尺寸。底部面板默认收起；窄窗口自动收起右侧列表。主题沿用应用深浅主题。工作台、策略测试器及常见运行提示跟随应用的中英文语言设置；已保存的脚本名称、源码和自选名称保持原样。

图表布局、画线、收藏指标、自选和自定义 Pine 脚本以当前浏览器的 IndexedDB 为正式存储，保存事务完成后显示“已保存”，重新打开自动恢复。首次使用会从旧服务端记录迁入一次，保留原记录，后续编辑不再上传这些文档。浏览器草稿、原版只读保护及多窗口版本冲突检查继续保留。顶部“布局管理”提供另存、重命名和删除，已保存布局通过下拉切换；Pine 编辑器提供自定义脚本的重命名和删除。删除会移除文档、历史版本及草稿，旧窗口的延迟保存不能把它恢复；主动导入备份仍可恢复数据。

宏观、资产观察、指标、资产研究及行情弹窗中的图表提供区间选择、放大、缩小和复位。ECharts 图表还支持框选时间段，双击图表可恢复完整视图。绘图工具和展开菜单各有独立点击区域，桌面至少 32 像素，触屏至少 44 像素。

“配置中心 → 浏览器个人数据”可以导出、导入已保存的数据及常用界面偏好。导入时保留当前内容，冲突记录另存副本，并调整布局引用的自选和脚本。备份可以在新的浏览器或网址直接导入；清理网站数据或更换浏览器、网址前应先导出。公开网站的研究观察列表、笔记、筛选配置、价格提醒和回测报告同样保存在浏览器。回测在浏览器 Worker 中计算，不上传个人脚本；提醒在网页打开期间检查公共行情，关闭网页后停止。普通本地模式保留原有服务端回测和提醒运行方式。

## 指标管理

顶部“指标”统一提供搜索和添加入口，包含“全部”“收藏”“我的脚本”和“当前图表”。点击指标名添加到活动图；星标收藏同时适用于基础指标和 Pine 脚本。“当前图表”只列出该图已添加的实例，可以设置参数、隐藏、显示或移除；移除实例不会删除脚本库中的源码。

内置“EMA + ZigZag++（发光特效版）”保留用户提供的 Pine v5 源码、五组 EMA、八个输入参数、双层折线及重绘开关。依赖固定为 DevLucem/ZigLib/1，原库源码和许可证保存在仓库中；运行时只做该版本所需的等价语法兼容，不替换成另一套 ZigZag 算法。已对照原库公式验证两组参数、各 600 根 K 线的方向和端点，并检查重绘／非重绘显示；这不代表已用同一份 TradingView 行情逐根比对。两端价格可能因交易市场、数据起点或实时更新时机不同而不同。

脚本库的原版保持只读保护，点源码按钮可以在 Pine 编辑器查看或另存修改。图表保存当时使用的源码、版本、参数及显示状态，修改库中的脚本不会悄悄替换已经放到图上的版本。默认允许重绘，因此当前未确认的 ZigZag 端点会随价格改变；关闭后仅绘制已确认的折线。

## Pine 编辑器

支持带 `//@version=5` 或 `//@version=6` 声明的脚本。可新建指标或策略、保存、另存、导入／导出 `.pine`。`Ctrl+S` 保存，`Ctrl+Enter` 添加到活动图。每次保存生成版本，图表保存源码、版本引用和参数；尚未保存的编辑草稿留在本地。

内置脚本库中的 ETH EMA55 v7.2 和 EMA + ZigZag++ 是受保护原版，修改后保存会新建副本。它们都是 `indicator()`，不能进入策略收益统计。

打开、导入和保存脚本会固定对应的文档及版本。快速切换脚本时，旧请求不会覆盖新选择；保存等待期间继续编辑的内容仍保留为未保存草稿。读取另一份脚本期间，编辑器暂时只读。

共享行情、旧记录迁入源及回测服务在 API 启动时初始化一次，由该进程持有本地目录锁；同一目录不支持同时运行多个 API 拥有者。浏览器中的个人文档独立于服务端运行目录。停止 API 时会等待正在创建的 Pine 子进程返回句柄并清理，尚未完成的运行保留为可重新运行的中断记录。

Pine 在独立 Web Worker 中计算，旧图表销毁时停止旧 Worker，运行超过 60 秒会终止。语法错误尽量定位到原始行列；运行新版本失败时保留原图成功运行的指标。重复添加是允许的，可在对象列表移除不需要的实例。

| 能力 | 状态 |
| --- | --- |
| v5/v6 输入、历史序列、常用 `ta`、条件、循环、`var` | 已接入，常用样例验证 |
| `plot`、填充、形状、标签、线、矩形、表格、指标副图 | 已接入，图表模型样例验证 |

## 策略测试器

打开或保存 `strategy()` 脚本后，选择运行区间、输入参数和资金／仓位／手续费／滑点。有效值的顺序是本次明确覆盖、脚本声明、引擎默认；“本次生效参数”可提前查看。

后台仅使用区间内已收盘的原始行情，执行 Pine 脚本声明和本次生效参数，不注入额外的固定预热、利润保护或末尾强制平仓规则。数据缺口、开始过早、结束不完整或不支持的品种会报错，不静默缩短后宣称完成。

结果提供权益曲线、收益、回撤、胜率、盈利因子、盈亏比、手续费、已平仓交易、未平仓状态和必要提示，支持导出完整报告。盈利因子为已平仓交易总盈利除以总亏损的绝对值；盈亏比为平均每笔盈利除以平均每笔亏损的绝对值，两者沿用已保存回测的费用口径。盈亏比不计入保本交易或未平仓盈亏；缺少盈利交易、亏损交易或历史统计时显示“—”并说明原因。旧回测可直接从已保存摘要计算，无需重跑。显示曲线时读取保留高低点的采样数据，统计和导出仍使用完整结果。

可以取消后台任务；关闭页面后任务继续，重开后从历史回测选择。应用退出会回收进程，未完成任务标为“已中断”。网页新建回测通过进程管道传递行情，结果直接写入 SQLite，不再同时保留完整输入、跨周期行情、结果 JSON 或引擎快照。运行进度只更新当前状态，不生成文档历史版本；脚本和布局的版本保存不变。旧版研究回测仍可读取，原有快照接口继续保留，但普通界面不展示重跑、订单流水和版本诊断。Pine 结果只在工作台保存，不进入研究结果目录。

## 开发与数据位置

默认同时运行 2 个任务，另外允许 8 个任务等待；队列满时明确拒绝新任务。排队超过 600 秒或开始执行后超过 300 秒会失败并说明原因，运行超时会终止对应进程。可通过 `.env.example` 中的 `PINE_RUN_*` 配置调整。Node 从 PATH 查找，也可通过 `NODE_EXECUTABLE` 指定。

下面是默认路径。未单独覆盖时，图表目录跟随 `RUNTIME_ROOT_DIR`；也可使用 `CHART_WORKSPACE_DIR` 单独指定。更改根目录不会搬迁已有数据，切回原根仍可读取原记录。

- 接口：`/api/v1/chart-workspace`，契约来自 `app/contracts/chart_workspace.py`，通过 `python -m scripts.generate_frontend_contracts` 生成前端类型。
- SQLite：`.opentrading_runtime/chart_workspace/workspace.sqlite3`，保存布局、自选、脚本版本和运行索引。
- 每次运行：`.opentrading_runtime/chart_workspace/runs/<id>/`，包含 `input.json`、`series.json`、`result.json`、`metadata.json`、进度及日志。
- 结果分页使用每次运行的 `records.sqlite3` 索引；新结果在完成前建立索引，旧结果第一次读取时在后台线程建立索引，后续页查询不会反复解析完整 JSON。原始快照保留用于重跑与核对。
- 引擎快照：`.opentrading_runtime/chart_workspace/engines/<sha256>/`，按内容去重保存 Worker、兼容代码及 PineTS Node ESM 文件。重跑校验清单与文件摘要；结果记录 Node 版本。
- 行情订阅：现货和 USDT 永续分别使用正确 Binance WebSocket；同品种同周期共享上游订阅。收到 K 线才显示实时，超过 30 秒没有消息则重连并使用 REST 补数据；消息带订阅代次与顺序，旧响应不能覆盖新订阅。
- Binance 永续行情地址使用 `/market/ws`，依据 [Binance 迁移说明](https://developers.binance.com/en/docs/products/derivatives-trading-usds-futures/websocket-market-streams/Important-WebSocket-Change-Notice)。

## 价格警报

在 K 线主图或价格轴上右键，选择“在该价格添加警报”，即可设置穿越、向上突破、向下跌破或达到指定价格。价位按交易品种的最小报价单位取整，图上用橙色虚线标出。拖动虚线或价格标签可以改价，按 Esc 取消拖动；点击虚线或标签可以编辑，标签上的 × 可以直接删除。顶部“警报”列表同样提供修改、暂停、继续监测和删除；手机也可以操作。默认仅触发一次，触发后自动删除规则和图上标记，通知照常送达。仅在主动选择重复提醒时保留监测规则，两次提醒至少间隔一分钟。

规则保存在数据库中，由 API 进程订阅相应交易所、现货或永续的价格流；切换图表或关闭网页不会取消后台监测。后台服务停止时不会监测，断线期间不补发历史穿越。触发结果会保存，并在网页打开后读取。

电脑端支持页面内提示、提示音和浏览器系统通知。需要保持网页打开，首次创建时允许通知；声音可通过“试听声音”启用。系统通知需要 localhost 或 HTTPS，以及浏览器和 Windows 允许通知。手机目前支持页面内提示和浏览器允许时的声音，尚未接入关闭网页或锁屏后的 Web Push。

## 代码职责

页面只负责能力组装与展示。`workspaceChart.ts` 持有图表、行情 Provider 与 Pine Worker 生命周期，`workspaceLayouts.ts` 持有布局版本、草稿和保存队列，`workspaceWatchlists.ts` 持有自选内容、版本化写入与报价轮询。`browserDocuments.ts` 负责浏览器正式文档、一次性旧记录迁入和版本事务，`browserDataBackup.ts` 负责已保存数据的导出与导入。`pineDocuments.ts` 管理脚本文档及本地草稿，`pineExecution.ts` 管理指标执行、超时与取消，`workspacePanels.ts` 管理面板尺寸及指针监听。切换页面或隐藏浏览器标签页时，工作台保留图表实例、已加载 K 线、视图位置和编辑状态，暂停图表行情更新、自选及警报列表轮询。实时模拟盘所需的价格订阅与服务端警报监测独立保留。返回时先补齐最后一根未确认 K 线和离开期间的历史，再接入最新行情并恢复轮询；补拉的历史不参与实时订单撮合。真正卸载工作台时才销毁图表、关闭订阅与 Worker；切页及卸载前都会保存布局状态。该行为同时适用于本地和公开网站。

## 免费日线行情

图表品种包含 VIX、ICE 美元指数 DXY、现有美股及中港股指数，以及商品期货和主要外汇。商品期货包括黄金、白银、铜、WTI 原油、天然气、玉米、小麦和大豆；外汇包括 EUR/USD、USD/JPY、GBP/USD、AUD/USD、USD/CAD、USD/CHF 和 NZD/USD。搜索支持中文名称及数据源代码，商品期货和外汇可分别筛选。

这些品种提供已完成日期的日 K，不提供盘中实时行情或分钟线。VIX 优先使用 Cboe 官方历史，DXY 使用 Yahoo 的 `DX-Y.NYB`；DXY 按 ICE 交易日处理。商品和外汇复用现有历史数据服务与缓存，商品标明为连续期货，外汇图表使用含开高低收的 Yahoo 数据。FRED 的每日外汇观察值不作为完整 K 线替代。

“美元流动性”页面中的贸易加权美元指数来自 FRED `DTWEXBGS`，与这里的 ICE DXY 分别保留。新增日线品种用于看图和指标研究，沿用指数的限制，不开放尚未验证的策略成交模拟。
