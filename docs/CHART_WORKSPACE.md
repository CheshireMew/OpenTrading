# 图表工作台

工作台位于首页 `/`。左上角菜单仍可进入研究、历史信号、市场及设置；工作台没有下单、AI 开单或自动交易入口。

## 看盘与保存

顶部选择品种和周期，布局支持单图、左右双图、上下双图、四图。带边框的是活动图，自选切图、指标添加和 Pine 运行都作用于它。默认只同步十字线和时间范围，品种和周期同步在“同步”中单独开启。隐藏的图表会保留状态，重新展开时恢复。

左侧绘图工具支持趋势线、射线、水平／垂直线、平行通道、矩形、斐波那契回撤、文字、箭头、画笔和时间／价格测量。工具分组中的小箭头可展开更多工具。选中对象后可修改样式、坐标、锁定、隐藏、复制、移除；顶部撤销、重做也可用于绘图。“对象列表”管理当前图的绘图和指标，“数据窗口”显示十字线所在位置的数值。

绘图使用时间与价格坐标，并按图表、市场品种隔离。现货与永续是两个不同品种；切换周期保留锚点。图表向左拖动时按需补历史，顶部“设置”可调整首次加载的历史根数。

右侧自选支持多个列表、新建、重命名、拖动排序、添加和移除品种。列表行情显示最新价、涨跌额和涨跌幅；24h 与交易日口径分别标注。工作台自选与“研究追踪”的观察列表独立。

拖动右侧或底部的分隔线调整面板尺寸。底部面板默认收起；窄窗口自动收起右侧列表。主题沿用应用深浅主题。

编辑会自动保存。只有后端确认写入后，顶部才显示“已保存”；离线更改保存在浏览器 IndexedDB，显示“未保存”。重开后可恢复未同步更改；遇到其他窗口的版本冲突，可恢复本地布局并另存，不会直接覆盖较新的服务端版本。布局可另存并通过顶部下拉切换。

## Pine 编辑器

支持带 `//@version=5` 或 `//@version=6` 声明的脚本。可新建指标或策略、保存、另存、导入／导出 `.pine`。`Ctrl+S` 保存，`Ctrl+Enter` 添加到活动图。每次保存生成版本，图表保存源码、版本引用和参数；尚未保存的编辑草稿留在本地。

内置“我的脚本”中的 ETH EMA55 v7.2 是受保护原版，修改后保存会新建副本。它是 `indicator()`，用来显示通道和信号标记，不能进入策略收益统计。

Pine 在独立 Web Worker 中计算，旧图表销毁时停止旧 Worker，运行超过 60 秒会终止。语法错误尽量定位到原始行列；运行新版本失败时保留原图成功运行的指标。重复添加是允许的，可在对象列表移除不需要的实例。

### 当前兼容边界（PineTS 0.9.34 / Heimdall 兼容层）

| 能力 | 状态 |
| --- | --- |
| v5/v6 输入、历史序列、常用 `ta`、条件、循环、`var` | 已接入，常用样例验证 |
| `plot`、填充、形状、标签、线、矩形、表格、指标副图 | 已接入，图表模型样例验证 |
| 已接入品种的多品种／多周期请求 | 使用统一后端行情与真实品种元数据；未接入来源报错 |
| `barstate` 与实时收盘确认 | 区分实际未收盘更新和收盘确认 |
| `varip` | 当前支持全局标量；局部变量及集合明确拒绝 |
| 策略多空、反手、加仓、部分退出、止损止盈、移动止损、撤单、费用和滑点 | 常用执行场景已验证；按原始订单、成交和持仓记录统计 |
| OCA、强平价格、跨币种换算、Bar Magnifier、`lookahead_on` | 阻止运行并说明原因 |
| 财报、经济数据、外部 Pine 库 | 未接入，阻止运行 |

这是一份受版本约束的兼容清单，不表示支持 TradingView 的完整 Pine 平台。实时标记由实际收到的行情更新计算；历史 OHLC 成交模拟不是逐笔行情还原。仅有收盘价的来源显示线图，不能用于策略成交模拟。USD／USDT 按报价数值记账，不进行汇率转换。

## 策略测试器

打开或保存 `strategy()` 脚本后，选择运行区间、输入参数和资金／仓位／手续费／滑点。有效值的顺序是本次明确覆盖、脚本声明、引擎默认；“本次生效参数”可提前查看。

后台仅使用区间内已收盘的原始行情。不套用研究页 Python 策略的固定预热、利润保护或末尾强制平仓规则。数据缺口、开始过早、结束不完整或不支持的品种会报错，不静默缩短后宣称完成。

结果提供权益曲线、收益、回撤、胜率、盈利因子、手续费、订单、成交、已平仓交易和未平仓状态。点击记录会加载该次回测的原始行情快照，并定位成交时间；“返回实时行情”恢复当前市场。

可以取消后台任务；关闭页面后任务继续，重开后从历史回测选择。应用退出会回收进程，未完成任务标为“已中断”。快照重跑复用源码、参数、行情和实际引擎文件，禁止在原快照缺少数据时联网补成不同样本。早期开发记录未保存引擎文件，仍可查看结果，但会明确要求新建运行。Pine 结果只在工作台保存，不进入研究结果目录。

## 开发与数据位置

- 接口：`/api/v1/chart-workspace`，契约来自 `app/contracts/chart_workspace.py`，通过 `python -m scripts.generate_frontend_contracts` 生成前端类型。
- SQLite：`.heimdall_runtime/chart_workspace/workspace.sqlite3`，保存布局、自选、脚本版本和运行索引。
- 每次运行：`.heimdall_runtime/chart_workspace/runs/<id>/`，包含 `input.json`、`series.json`、`result.json`、`metadata.json`、进度及日志。
- 引擎快照：`.heimdall_runtime/chart_workspace/engines/<sha256>/`，按内容去重保存 Worker、兼容代码及 PineTS Node ESM 文件。重跑校验清单与文件摘要；结果记录 Node 版本。
- 行情订阅：现货和 USDT 永续分别使用正确 Binance WebSocket；同品种同周期共享上游订阅。收到 K 线才显示实时，超过 30 秒没有消息则重连并使用 REST 补数据；消息带订阅代次与顺序，旧响应不能覆盖新订阅。
- Binance 永续行情地址使用 `/market/ws`，依据 [Binance 迁移说明](https://developers.binance.com/en/docs/products/derivatives-trading-usds-futures/websocket-market-streams/Important-WebSocket-Change-Notice)。

依赖锁定在 `frontend/package-lock.json`。`npm ci` 的 postinstall 会执行 `frontend/scripts/patch-pinets.mjs`，只对已校验摘要的 PineTS 0.9.34 Node／浏览器 ESM 文件应用限价成交滑点修正。限价入场、止盈成交不再误加市场／止损滑点；依据 [Pine 策略声明说明](https://www.tradingview.com/pine-script-docs/language/declaration-statements/)。升级依赖必须重新核对补丁及兼容样例。

许可证及署名在 [licenses/chart-workspace](licenses/chart-workspace/manifest.json)。Vela 保留可见署名，Vela-pinets 与 PineTS 使用 AGPL-3.0-only，Monaco 使用 MIT。兼容层和补丁源码随仓库保留。
