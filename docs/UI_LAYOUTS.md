# 页面布局与切换

布局选择按页面保存，不切换数据源，也不重新运行计算。相同页面内切换时，搜索条件、当前选择、表单输入和已有结果由同一份页面状态继续维护。刷新页面时只保证恢复布局偏好；业务数据和其他偏好仍沿用各模块已有的恢复机制。

| 页面 | 布局 | 用途 |
| --- | --- | --- |
| 股票目录 | 双栏、平台对照、左侧筛选 | 查看证券、比较产品覆盖、连续筛选 |
| 币安行情 | 行情表格、列表与详情、左侧筛选 | 扫描数据、连续查看交易对、筛选结果 |
| Web3 榜单 | 行情表格、列表与详情 | 比较代币、查看行情与合约详情 |
| 市场指标 | 图表概览、紧凑列表 | 查看趋势、快速比较指标数值 |
| 资产对比 | 比值为主、价格并排、单图放大 | 比较相对强弱、观察两资产价格、放大一张图 |
| 定投 | 参数与结果、结果全宽 | 调整输入、查看计算结果 |
| 组合资产 | 行情表格、列表与详情 | 编辑目标权重、查看单项持仓 |
| 图表工作台 | 图表专注、自选常驻、编辑器 | 分配主图、自选列表与编辑器的空间 |

组合总览使用已有流水接口的总权益、盈亏、收益率和现金余额；配置偏离沿用再平衡模型。配置权重的分母是资产市值，现金余额单列，页面明确说明此口径。未知收益率保留为空，不填充为零。载入和错误由同一份流水请求状态反馈，切换组合会清除上一组合的摘要。

行情详情沿用现有图表和研究数据。表格模式中的行主体可点击，原生按钮保留键盘入口；双栏模式中点击选中项可收起详情。内嵌详情不锁住页面焦点，浮层详情继续使用原有焦点管理。连续切换代币或交易对时，只有当前请求能够更新详情。K 线请求同时区分交易对、市场来源、周期和请求批次，避免同名现货与合约的数据交叉；历史补载和实时增量遵循相同规则。切换链或关闭详情会使旧请求失效，空历史与加载状态分别反馈。

行情筛选在窄屏折叠，双栏改为上下排列。资产对比的单图模式保留三张图的组件实例；定投隐藏配置时保留输入和结果。图表工作台切换面板只改变面板空间，不重建主图，不改变交易对、周期、绘图或脚本；手动展开其他面板后，按钮按实际状态显示，已有自定义布局仍可恢复。

通用布局选择器为带按下状态的原生按钮组。偏好存储在 `opentrading:layout:<page>`，股票目录保留其既有键。无法访问浏览器存储时，当前会话仍可正常切换。设置、数据健康和减半页分别使用单一默认布局。

## 验证边界

在 Windows 的本地预览副本上验收。行情、资产对比、定投、组合和图表工作台连接现有本地 API；预览库中组合为既有验收样例。指标历史为空和 Web3 上游不可用时，另用独立端口的固定样例验证完整界面、详情、快速切换与响应式，样例不写入产品数据，也不代表实时行情。未执行实际交易。
