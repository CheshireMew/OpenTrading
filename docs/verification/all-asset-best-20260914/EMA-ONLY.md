ETH本次完整六年（2020-09-10起）另一个版本为+61,653.56%：不限等待根数、盘中突破信号收盘价、5分钟成交及保护；2,547盈利、6,741亏损、1持平、胜率27.42%、回撤29.60%。该区间与表中ETH不同。旧+79,500.54%使用有利成交顺序假设，本次84笔核对为63笔明确止损、4笔最终盈利、17笔仍先后不明，不能把旧有利数字当成5分钟数据已证实的收益。

ZEC之前+1,056.97%是旧版最近两年片段，不是七年最高。BTC旧15分钟调参最高+562.74%是八年区间，表中1小时+900.22%是近六年区间，不能据此断言1小时在相同八年一定更好。
