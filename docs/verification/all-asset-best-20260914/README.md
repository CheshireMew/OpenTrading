BNB、BTC：日线收盘与30根以前的收盘比较，高于做多、低于做空，方向变化时下一根开盘平仓或反手；相等时退出。入场止损距离固定为当时ATR14×3，不叠加2%启动的利润保护，止损后等新的方向变化。

ZEC：4小时收盘与90根以前比较，其余逻辑同上，ATR14×3初始止损，不带利润回吐保护。这三个是较早测试的动量策略，不是最近修改的EMA通道。

## ETH另有更高数字，成交先后采用有利假设

2020-09-10—2026-09-10，15分钟，累计+79,500.54%，9,277笔：2,547盈利、6,729亏损、1笔持平，胜率27.45%，最大回撤28.71%。

参数为EMA55、振幅31、门槛0.4、不追2倍、固定止损1%、浮盈2%启动、回吐50%、15分钟收盘更新保护。原信号后盘中突破信号收盘价即可入场，不限制等几根；遇反向信号取消旧等待。

这一组将入场当根的不利极值假设为发生在入场前。它属于执行顺序敏感性对照，不能认定实盘一定按有利顺序发生。相同策略按先后不明算止损，收益为+54,411.30%。因此更高的+79,500.54%单独列出，不冒充后续保守口径的最高版本。

主表ETH+64,338.16%实际从2020-12-28开始；同参数从2020-09-10起的六年版本是+61,349.61%。最近交付的Pine取消了5分钟保护，没有对它重新回测，不能把此表收益套到新版Pine。
