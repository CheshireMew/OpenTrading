# BNB：低波动是否应该禁止入场

结论：现有数据不支持把“平滑振幅低于价格0.4%”直接设为禁止入场条件。本轮完成原版7903笔交易的逐年检查，没有改策略或启动新回测。按预先保存的计划，证据不足即停止，不继续搜索其他门槛。

“振幅”使用原策略 EMA(high-low,50)，除以当时收盘价。0.4%沿用之前归因中的档位，不是入场突破门槛0.8倍，也不是整个通道的宽度。所有特征均来自实际成交委托挂出前已收盘的15分钟K线，未使用入场K线后来的高低价。

2019—2022年低波动组每年净贡献均为正，其中2019、2020年每笔平均收益还高于高波动组。2021年低波动仅35笔，样本不足。2023年两组都亏，高波动组每笔反而亏得更多。后期的2024年低波动组也更好；关系没有稳定保持一个方向。

选择规则只使用2023年之前已平仓的交易，跨分界交易不参与早期判断；后期另看。计划要求早期低波动组整体亏钱、在至少3个完整年份更差，且样本足够。实际低波动组整体赚钱，仅2个年份按每笔平均对数收益更差，2021年样本也不足，故不启动过滤回测。全部历史此前已看过，这仍属于历史复核，不是未见数据验证。

## 这次真正发现了什么

波动更大确实更容易达到2%浮盈：全期高波动组达到过门槛的比例约38.39%，低波动组约17.94%。高波动组胜率40.02%，低波动组27.43%。但高波动组赚钱单平均赚2.00%，亏损单平均亏1.19%；低波动组赚钱单平均赚1.47%，亏损单平均亏0.51%。因此不能只看触发保护的概率或胜率，忽略亏损幅度同时扩大。

全期低波动组3066笔，841笔赚、2222笔亏、3笔保本。若每笔本金同为100，盈利合计1237.65，亏损合计1123.16，净贡献仍为+114.49。早期净贡献+73.02，后期+41.07，另有一笔跨分界交易；不能把“低胜率”直接当成“应该删除”。这些是旧交易的分组金额，新过滤会改变持仓和后续机会，不能将分组净额冒充新策略的收益变化。

原最大回撤阶段，两组旧交易都净亏。低波动组每笔平均亏0.055%，高波动组每笔平均亏0.099%。因此该段回撤不能仅归因于波动太小。

单笔收益最高的20笔中，有3笔入场前也属于低波动，分别赚14.09%、13.73%、12.81%。这说明入场前安静的行情，也可能在入场后扩大波动；直接过滤还会错过这些机会。

本轮保留原版，不添加该过滤条件。结论仅针对本次既定分界，不能扩大成“所有波动指标都无用”，也没有证明任何替代条件有效。
