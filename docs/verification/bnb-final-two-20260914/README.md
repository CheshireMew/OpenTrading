## 具体发生了什么

5分钟组交易约为原版2.75倍，胜率降低，平均持仓由约6.47小时缩短至2.59小时。15,265笔亏损中，14,878笔是反向信号退出，385笔是固定止损，2笔是利润保护退出。它并非每一年都差：2019年亏75.12%，但2022年至2026年9月10日各年均为正，2023年反而赚43.88%。后面的盈利主要在填补早期损失，不能把全期结果简化成所有年份都不适合5分钟。

5分钟组最大回撤对应高点为2018-09-10 01:50 UTC，低点为2021-05-19 00:55 UTC，直到2026-06-01 09:50 UTC才恢复该前高，相隔约2821天、7.72年。原版参数对应的EMA时间长度和确认等待时间在5分钟上都缩短了，本轮没有重新优化这些参数。

4%止损组固定止损亏损从598笔降到72笔，但反向退出亏损从4523笔增至4948笔。放宽固定止损并未消除大多数反向退出，亏损单平均亏损从约0.892%增至0.916%，盈利单平均收益约1.834%，与原版约1.839%基本接近。这是整体交易记录的对比，不是每笔一一对应的因果归因。

4%组最大回撤仍发生于2022-07-29 18:15至2024-01-20 17:00 UTC，于2025-10-14 12:45 UTC恢复原高点；从前高到恢复约1173天。2023年亏52.27%，没有改善原版该年约51.29%的亏损。

## 参数及核对

保留EMA55、平滑高低差周期50、突破0.8倍、超过1.5倍不追、第2或第3根盘中突破信号实体确认、浮盈2%启动保护、回吐50%、反向信号退出、禁止止损重进。4%组只改initial_stop_pct，stop_method仍为0，振幅止损上下限不参与计算。

两组实际利润保护频率均为5分钟。5分钟组直接在原生K线收盘更新，不再另指定一个相同周期的细周期；因此配置中的execution_timeframe为空、intrabar_profit_protection为false，这不表示取消利润保护。15分钟组仍用5分钟细周期成交及更新保护，没有改成1分钟。

最大回撤按各信号周期收盘权益：5分钟组每5分钟，原版及4%组每15分钟，采样精度不同。旧版7根细周期不匹配回退在4%组保持一致；盘中先后不明分别为原版5笔、5分钟组10笔、4%组1笔，均沿用保守处理。
