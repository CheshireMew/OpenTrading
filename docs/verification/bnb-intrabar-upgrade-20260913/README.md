# BNB：原版、最近优化、ETH 参数对照

BNB 自己的参数加上盘中确认和更快利润保护，收益提高；直接搬用 ETH 参数，收益反而较低。这是指定参数的历史对照，没有重新挑选 BNB 的最优参数。

BNB 区间为 2018-09-10 至 2026-09-10，15分钟信号，使用相同5分钟行情模拟成交。每笔投入当时全部资金，盈亏计入下一笔本金，不计手续费和滑点。

| 版本 | 累计收益 | 胜率 | 赚钱次数 | 亏钱次数 | 保本 | 总笔数 | 最大回撤 |
|---|---:|---:|---:|---:|---:|---:|---:|
| BNB 原版，同一成交行情重算 | +2,802.79% | 34.59% | 2,842 | 5,355 | 19 | 8,216 | 69.04% |
| BNB 原参数＋盘中确认＋更快保护 | **+4,099.55%** | **35.14%** | 2,777 | 5,123 | 3 | 7,903 | 68.19% |
| ETH 优化版整套参数用于 BNB | +848.60% | 27.29% | 3,472 | 9,238 | 14 | 12,724 | 73.16% |

BNB 旧记录为 +2,804.34%。这次原版重算使用更细的5分钟成交行情，得到 +2,802.79%；新旧15分钟价格数据逐行一致。以重算原版作为本次直接对照，避免把成交精度变化全部归为策略改善。

ETH 优化版在 ETH 自身 **2020-09-10 至 2026-09-10 的六年**记录为 **+61,349.61%**，胜率27.39%，共9,289笔，2,544笔盈利、6,744笔亏损、1笔保本，最大回撤29.46%。这是已有结果，直接复用；和 BNB 八年总收益不是同一区间排名。

## 参数和改动

| 参数 | BNB 自己的参数 | ETH 优化参数 |
|---|---:|---:|
| 交易周期 | 15分钟 | 15分钟 |
| 中心线 EMA（每根最高与最低价的平均数） | 55 | 55 |
| 平滑振幅周期（最高价减最低价的 EMA） | 50 | 31 |
| 离开中心多少倍振幅触发原信号 | 0.8 | 0.4 |
| 离中心超过多少倍振幅不追 | 1.5 | 2 |
| 固定止损 | 2% | 1% |
| 浮盈达到多少启动保护 | 2% | 2% |
| 允许回吐最高浮盈 | 50% | 50% |

原版在信号收盘后，下一根开盘入场。本次两个优化版均改为：把信号K线算作第1根，仅第2或第3根盘中突破信号实体才入场；利润保护由每15分钟收盘更新改为每5分钟收盘更新，下一根生效。反向信号退出保留，没有增加振幅止损或止损后重新入场。

BNB 优化后的胜率只提高约0.55个百分点，亏损次数仍比盈利次数多，最大回撤仍约68%。这次改善不能表述为已经解决频繁亏损或稳定盈利。
