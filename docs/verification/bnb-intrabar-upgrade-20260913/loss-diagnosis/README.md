# BNB 优化版：亏损与68%回撤

结论：主要问题是大量短暂突破后的反向退出，尤其是2022年下半年至2024年初。不是某一笔亏掉68%，也不是固定2%止损造成了大多数亏损。只分析既有7903笔交易，没有改参数或重跑策略。

| 亏损退出原因 | 笔数 | 占亏损笔数 | 平均亏损幅度 |
|---|---:|---:|---:|
| 原反向信号退出 | 4523 | 88.29% | 0.75% |
| 固定2%止损 | 598 | 11.67% | 2.00% |
| 利润保护退出仍亏损 | 2 | 0.04% | 0.30% |

若把每笔本金设为一样大，再相加亏损幅度，反向退出占73.82%，固定止损占26.16%。这与上表的笔数占比不是同一口径。5123笔亏损中4063笔退出前记录的最高浮盈不足1%，1058笔达到1%但不足2%，只有2笔达到2%。大部分尚未有足够浮盈启动保护就已经掉头。

账户最大回撤：2022-07-29 18:15 UTC 的476362.79跌至2024-01-20 17:00 UTC 的151548.38，下降68.19%，历时约540天；到2025-12-03 06:00 UTC才恢复前高，距原高点约1222天。北京时间分别为7月30日02:15、1月21日01:00、12月3日14:00。初始本金10000，所以这是从已赚到的账户高点回落，不是初始本金亏掉68%。

这段回撤内平仓1374笔，369笔赚、1004笔亏、1笔保本，胜率26.86%。盈利单平均赚1.47%，亏损单平均亏0.64%：一笔盈利约抵2.31笔亏损，但实际每赢一笔伴随2.72笔亏损，因此总体无法抵消。975笔亏损来自反向退出，固定止损只有29笔。

平仓交易净亏296282.51，占账户跌幅约91.22%；剩余28531.90来自峰谷两端浮动盈亏的变化。多单净亏135104.43，空单净亏161178.08，两边都有问题。分方向金额来自原双向交易记录，不能当成取消某方向后的新回测收益。

回撤期入场前平滑单根振幅中位数为价格的0.345%，其他时期约0.495%；退出前记录浮盈达到2%的交易比例约19.58%，其他时期约32.75%。这与“信号仍然不少，但随后可赚的幅度和延续不足”相符。仅突破信号实体没有保证持续行情；这些是事后描述，不能宣称依据宽度过滤就一定改善。

最长19笔连亏出现在2023-09-02至09-07（UTC），该段累计亏6.40%，并不是全部68%回撤都由这19笔造成。2023全年亏51.29%；2018年9月至年底亏23.16%，2026年至9月10日亏16.64%。其余自然年账户收益：2019 +162.99%、2020 +45.76%、2021 +468.21%、2022 +123.96%、2024 +28.31%、2025 +115.06%。2022全年盈利仍可与年中开始的大回撤同时存在。
