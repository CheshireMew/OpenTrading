# BNB：每笔投入100%、50%、25%的对照

结论：减少投入比例明显降低了账户回撤，也降低了累计收益。每笔投入25%时，八年收益+239.08%，最大回撤23.44%；但最大回撤对应的前高仍需约3.16年才恢复。减少仓位没有改变胜率或交易质量。

BNB/USDT、15分钟，2018-09-10至2026-09-10 UTC；初始10000，每次按当时账户资金的指定比例投入，余额保持现金，无利息、手续费或滑点，不加杠杆。原版交易参数完全保留：EMA55、振幅周期50、突破0.8倍、超过1.5倍不追、第2或第3根盘中突破信号实体确认、固定2%止损、浮盈2%启动保护、回吐50%、每5分钟更新保护。
