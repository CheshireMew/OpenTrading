# BNB：延后反向退出、换周期、缩小止损

结论：四个单独改动都没有解决原版的大回撤。1%止损略微降低回撤，但收益和胜率也下降；浮盈达到2%才允许反向退出，胜率超过50%，收益却大幅下降，回撤更大。

本轮“原版”指 BNB 已优化版本：15分钟、EMA55、平滑振幅周期50、突破0.8倍、超过1.5倍不追；第2或第3根盘中突破信号实体确认入场，固定2%止损，浮盈2%启动保护，允许回吐最高浮盈的50%，每5分钟更新保护。不是最早的截图拟合版本。

所有组均为 BNB/USDT，2018-09-10至2026-09-10（UTC），初始资金10,000，每笔投入当时全部资金并复利，不计手续费和滑点。成交及保护更新均采用相同5分钟数据。每组只改表中所述因素，其他参数不变；没有重新选出各周期的最优参数。

## 为什么延后反向退出反而更差

保护启动前禁止反向退出，也禁止反向开仓，固定2%止损始终有效。保护启动后，本笔仓位一直允许响应新的反向信号，不补执行之前忽略的信号。

反向退出的亏损确实被消除了，但固定2%止损从598笔增至1,882笔。逐笔收益率口径下，亏损单平均亏损由约0.89%扩大到约2.00%，赚钱单平均收益仅由约1.84%增至约2.03%。减少小亏并没有消除风险，一部分交易变成了更大的亏损。

在入场时间、方向和价格完全相同的1,528笔原版反向亏损单中，延后退出使419笔转为盈利，1,109笔亏得更多。前者平均盈利2.17%，后者平均亏损2.00%。这只是相同入场的配对；持仓变长还会改变其余入场机会，不能把它当成对全部原版交易逐笔独立替换的结果。

## 换周期和1%止损的实际作用

30分钟和1小时减少了交易并提高胜率，但最大回撤仍在约67%—69%。1小时在2023年亏得更少，却没能提高全期收益或明显降低全期最大回撤。这次结果不支持“只把周期放大就能解决BNB回撤”。

1%止损将最大回撤降低约3.54个百分点，但亏损笔数由5,123增至5,856，胜率降低约3.93个百分点。它控制了部分单笔损失，同时更容易被止损，改善幅度有限。
