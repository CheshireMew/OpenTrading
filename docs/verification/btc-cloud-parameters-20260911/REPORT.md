# BTC 参数选择与后续两年验证

这3个完成后续两年测试的版本中，EMA55 · 振幅50 · 止损2% 收益最高：最后两年 +47.98%，完整八年 +562.74%。

BTC/USDT，15分钟。2018-09-10—2022-09-10：前四年选参数；2022-09-10—2024-09-10：中间两年筛选；2024-09-10—2026-09-10：最后两年验证。
