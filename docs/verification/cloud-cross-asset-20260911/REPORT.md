# ETH六年与BTC八年策略复测

逐项结论已补全：见 [早期12个策略的8个问题与结论](FINDINGS.md)，包括通道是否有用、ATR是否有额外帮助，以及各版本对照的限制。

ETH六年最高累计收益：+25,829.05%；BTC八年最高累计收益：+222.69%。

ETH/USDT：2020年9月10日至2026年9月10日，六年；BTC/USDT：2018年9月10日至2026年9月10日，八年。都使用15分钟K线，另列BTC与ETH相同的六年。按收益率排序，胜率不参与排名。

初始资金10,000，每笔投入当时全部资金，盈亏计入下一笔本金，不加杠杆，不计手续费和滑点。收益是整个区间的累计收益，不是年收益。收盘确认信号，下一条实际K线开盘成交。

48个策略版本中，ETH六年累计盈利41个，BTC八年累计盈利12个；每个年度都盈利的分别有5个、0个。ETH第一名原参数直接用于BTC八年，收益为+131.78%，排名第3。

按你要求只看收益，BTC八年第一仍低于同期买入持有的+1,149.86%；这组第一名最近两年在BTC的收益为-15.78%。因此，部分优化在ETH上有很高的历史收益，但本轮还不能确认它能稳定适用于其他市场。

最早EMA31候选中，只把ATR换成平滑高低差，ETH六年从+743.50%变为+743.79%，BTC八年从-72.24%变为-72.13%。没有看到ATR明显提高收益。另外，原脚本ATR1.5版在BTC相同六年里排名第一，但拉到八年又变为亏损；缩短或改变起止年份，确实可能改变结论。

BTC测试前已固定全部版本，本轮没有根据BTC结果调参。ETH已反复研究，BTC与ETH也属于相关市场；跨币种和更长年份的结果能帮助判断，但不能证明没有过拟合或以后必然盈利。这里的第一名仅指这48个已选版本。
