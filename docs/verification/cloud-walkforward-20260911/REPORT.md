# 四个标的：周期选择、利润保护和 ATR 止损比较

本轮已完成。没有找到一种在四个标的、不同阶段都占优的选参或退出办法。收紧利润保护、增加反向确认，都有代价；ATR 加两根确认尤其不能直接推广到所有标的。

## 1. 怎样选周期和参数，后来有没有用

每半年只使用之前三年选参数，然后在接下来的半年执行。比较两种办法：第一种要求附近参数也有较好的典型表现；第二种直接选择过去三年收益最高的合格版本。如果过去没有合格版本，就空仓。整个选择办法、候选范围在后续分段重放前锁定，没有看到后续结果再修改。

下面是 **2023-10-01 至 2026-09-10** 的累计收益。每次可以选 5 分钟、15 分钟、半小时或 1 小时。按当前全部本金复投，不加杠杆，不计手续费和滑点。所有对照都在事先确定的半年边界清仓，盈亏带入下一段。因此不能与此前不同起止日期、不中断持仓的两年结果直接比较。

| 标的 | 要求附近参数也表现较好的选择办法 | 直接选过去三年收益最高 | 固定原 ETH 小时参数 |
| --- | ---: | ---: | ---: |
| PAXG | +25.99% | +61.51% | +47.32% |
| ZEC | +60.05% | −2.39% | +59.33% |
| ETH | +110.96% | +972.79% | +341.07% |
| BTC | +89.31% | +94.93% | +104.22% |

较严格的选择办法只在 ZEC 上略高于固定参数，差 0.72 个百分点。它在 PAXG 有四段空仓、ZEC 两段空仓；ETH 最近两段都亏，合计 −18.32%。所以，选择时不看后面的行情是必要的约束，但不等于这套选择规则本身有效，也不等于定期换参数会比固定参数更好。

直接选过去第一名在 ETH 上确实表现突出：3,482 笔，987 笔赚、2,494 笔亏、1 笔保本，胜率 28.35%，六段中五段赚、一段亏。这不是事后逐段挑后续赢家，但同样办法在 ZEC 上亏损，不能把 ETH 的结果当成跨标的有效的证明。ETH 前两段选 15 分钟 EMA55，之后选半小时 EMA34，利润保护在预定候选之间变化；逐段参数全部列在页面中。

加入日线需要足够的共同预热与此前三年历史，因此只能对 **2025-10-01 至 2026-09-10** 的两段进行同样比较。四个标的共八次联合选择，都没有选中日线。这只说明它没有胜出于本轮范围和选择标准，不能认定日线普遍无效，也不能将这不到一年的累计收益与上面近三年直接排名。

## 2. 最高浮盈回吐 50%，是否应该改小

为避免同时改变入场，下面四个标的都固定为：**1 小时，中心 EMA55，高低差 EMA31，突破 0.4 倍，离中心超过 2 倍不追，初始止损 1%，浮盈达到 2% 启动保护，反向一根收盘确认。** 每行只改变利润保护。

| 保护方式 | PAXG | ZEC | ETH | BTC |
| --- | ---: | ---: | ---: | ---: |
| 允许回吐最高利润的 50% | +47.32% | +59.33% | +341.07% | +104.22% |
| 改成回吐 35% | +23.84% | +41.60% | +128.87% | +16.46% |
| 改成回吐 25% | +18.93% | +21.07% | +77.84% | +9.78% |
| 回吐 50%，另加价格回撤 5% 上限 | +34.06% | +11.64% | +362.35% | +81.94% |
| 回吐 50%，另加价格回撤 10% 上限 | +47.32% | +69.98% | +327.80% | +104.22% |

这段历史里，直接收紧到 35% 或 25%，四个标的的收益都下降。原因是保护线变近后，正常回调也更容易触发离场，后续并不会自动在原位重新买回。已经平掉的仓位，不能继续获得后来那段趋势的利润。5% 价格回撤上限只提高了 ETH 的累计收益，10% 上限提高了 ZEC，仍然没有统一赢家。

因此，50% 可以继续作为比较基准，但还不能说它永久最优。只看 2025-10 以后的短段，BTC 的 25% 保护反而比 50% 高，ETH 的 5% 价格上限则不再占优，说明优劣会随行情改变。

100 买入、最高到 200 的例子中：回吐 50% 对应保护价 150，增加 5% 价格回撤上限对应 190，10% 对应 180。反向信号始终是另一条平仓路径，可能在保护价触发之前就平仓；若反向入场没有超出追价限制，可以同时换成反向持仓。止损和保护先触发时也会先退出。

## 3. ATR 止损加两根反向确认，实测怎样

仍固定相同的小时入场参数和 50% 利润回吐，只改变下表两项。ATR 使用 ATR14，乘数确定的距离替代原来的 1% 初始止损，不是额外再叠一条 1% 止损。距离按已收盘信号确定，锚定实际入场价。

| 初始止损 / 反向确认 | PAXG | ZEC | ETH | BTC |
| --- | ---: | ---: | ---: | ---: |
| 1% / 一根 | +47.32% | +59.33% | +341.07% | +104.22% |
| 1% / 两根 | +82.05% | +41.08% | +180.66% | +47.98% |
| 2 倍 ATR / 一根 | +60.46% | +14.27% | +289.29% | +53.38% |
| 2 倍 ATR / 两根 | +54.09% | −71.15% | +278.56% | +21.88% |
| 3 倍 ATR / 一根 | +70.25% | +45.30% | +295.97% | +37.43% |
| 3 倍 ATR / 两根 | +97.14% | −60.25% | +188.60% | +34.29% |

PAXG 在这段近三年里有改善，其他三个标的没有。PAXG 也不能直接确立新版本：只看最后两段，原版 +71.95%，3 倍 ATR 加两根确认只有 +48.18%，说明它的优势并不贯穿所有时期。

ZEC 的反例最清楚：

| ZEC | 原 1% 止损＋一根确认 | 3 倍 ATR＋两根确认 |
| --- | ---: | ---: |
| 交易数 | 1,707 | 1,082 |
| 赚钱 / 亏钱 | 552 / 1,155 | 623 / 459 |
| 胜率 | 32.34% | 57.58% |
| 平均赚一笔 | +2.23% | +2.07% |
| 平均亏一笔 | −0.98% | −2.87% |
| 累计收益 | +59.33% | −60.25% |

放宽止损和多等确认，确实使一些原来的亏单恢复盈利，但留下来的亏单更大。在 3 倍 ATR 版本中，仅从一根改两根，平均亏损从 2.23% 扩大到 2.87%；因初始止损退出的交易从 30 笔变成 87 笔，这类退出平均约亏 4.50%。赚的小钱不够抵消大亏损。

进一步匹配相同时间、方向、价格的入场：ZEC 使用 3 倍 ATR 时，原来因反向信号退出、且两版能匹配的 290 笔中，多等确认后 92 笔变好、196 笔变差、2 笔相同；另有 281 笔无法匹配。最明显的一笔，相同多单原来亏 3.37% 退出，多等一根后触及 ATR 止损，亏 11.54%；也有亏 2.30% 的单变成赚 13.79% 的例子。两种情况都真实存在，不能只挑“多等就救回”的图例。

匹配分析只解释能匹配的部分交易，不等于账户的全部变化；不同退出还会改变后续实际入场。详细记录见 `exit-pair-diagnosis.json`。

## 4. 目前应该怎样看待这些结果

保留原来的小时参数和 50% 利润保护作为统一比较基准；不因为某个标的这次第一，就把 ATR 或双确认替换到所有标的。较严格的自动选参办法没有得到普遍改善的支持，不能以“考虑了附近参数”作为有效性的证明。直接选择过去收益最高的办法在 ETH 上值得保留观察，但当前证据不支持把它当成四个标的的统一答案。

这轮也没有普遍解决“亏损次数多于盈利次数”的问题。ZEC 虽有版本达到一半以上胜率，却出现明显亏损，不能为了胜率放弃对亏损幅度的约束。

研究到此完成本轮固定范围，不继续看着后续结果追加参数来挽救赢家。这些历史和相关策略此前已被研究过，所以本次是按时间顺序进行的回顾性检验，不是真正从未接触过的新行情，也不能证明消除了过拟合。
