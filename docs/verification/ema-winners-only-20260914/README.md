# EMA通道六个最高收益版本：只保留盈利与亏损拆解

只读取已完成交易，没有重新回测，没有改策略。SOL采用最新+62,757.43%版本；BTC、BNB采用收益更高的原版；ETH采用2020-12-28开始的+64,338.16%固定版；ZEC和PAXG分别采用+582.26%、+245.48%版本。参数、精确来源和区间见plan.json。

“只保留盈利”指事后知道输赢，保留原盈利交易的入场、退出及收益率，所有亏损交易不参与资金变化，再按每笔全部资金复投。不能提前实现这一筛选，也不等于只删除震荡损失。它没有模拟删除旧交易后可能出现的新交易，不是修改策略后的真实回测。
