价格刚刚走出门槛，就顺着方向做一笔

先画一条跟随价格的中心线，再在它上下各留一点距离。收盘向上越过上面的线，考虑做多；向下越过下面的线，考虑做空。如果一下冲得太远，就放弃这次新入场。

“离中心多远”，到底是什么？

就是收盘价与中心线之间相差多少钱。中心 EMA55 是一条加权平均价格线，近期价格权重更大。再用每根 K 线的最高价减最低价，按 EMA50 平滑，估算最近常见的波动幅度。

例如中心价是 100，常见振幅是 10，那么 0.8 倍就是 8：做多门槛在 108，做空门槛在 92。最远距离 1.5 倍就是 15；向上突破却已经超过 115，就不追这次多单。0.8 倍振幅不是上涨 0.8%。

中心线和振幅每根都会更新，上下门槛也会一起移动。图中展示真正参与买卖判定的线；当前策略图里的较窄彩色云带只用于显示，变色本身不会下单。

这套策略靠什么赚钱，什么时候退出？

它押注的是：价格走出一段距离后，还能沿这个方向继续走。如果突破后马上掉头，就可能亏损。价格持续在线外，不会因此每根都加仓；需要新的穿越信号，并且同一方向只持有一笔。

当前 BTC 版入场后设 2% 初始止损；浮盈达到 2% 启动保护，允许回吐最高浮盈的 50%；出现反向信号也平仓。这些退出条件谁先触发就执行。

突破信号在本根收盘确认，回测按下一根开盘成交。若反向突破太远，仍可平掉旧仓，但不会新开反向仓。利润保护按已完成 K 线更新，从下一根开始生效。
