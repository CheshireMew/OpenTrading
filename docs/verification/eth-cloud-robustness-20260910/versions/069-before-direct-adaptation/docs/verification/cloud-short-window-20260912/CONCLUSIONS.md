# 本轮可使用的结论

本轮结果只适用于已固定的24套交易参数、20笔完整交易门槛、12种观察与检查办法。退出规则没有参与选择。完整交易期间是2020-12-28至2026-09-10，后两年为2024-09-09至2026-09-10。当前本金全额复投，无手续费、滑点或杠杆。

## ETH：短窗口选参值得保留，但不能只宣布全期第一名

12种办法的全期收益都超过固定原小时参数，后两年有9种超过。优势不是只发生在一个孤立组合，但幅度对窗口和检查频率敏感。

- 看8周、每2周检查：全期+11,688.42%，后两年+758.10%。12,168笔，3,345笔赚钱、8,822笔亏钱、1笔保本；胜率27.49%，最大回撤51.20%。
- 看8周、每4周检查：全期+7,377.20%，后两年+737.46%。
- 看8周、每周检查：全期+3,291.21%，后两年+404.83%。
- 固定小时参数：全期+1,450.99%，后两年+219.42%。

以上是看完整段结果后得到的比较。只用较早年份选定的是“看12周、每4周检查”，其后两年+215.71%，略低于固定版。不能把后来才知道的8周第一名替换进早期选择，声称提前找到了最优办法。

全期最高版本的年度收益：2021年+271.00%、2022年+174.02%、2023年−31.36%、2024年+113.16%、2025年+470.94%、2026年至9月10日+55.11%；2020年末不足一周−10.50%。不只一年贡献收益，但并非每年盈利。总收益是多年复利，不能把+11,688.42%读成每年收益或等额每笔投入收益。

## BTC：本轮固定小时参数优于全部短窗口选择

固定原小时参数全期+769.94%；12种里最高的“看12周、每4周检查”只有+210.27%。后两年固定版+60.73%，12种短窗口办法全部落后。较早年份同样选中12周＋4周，但后来两年亏24.58%。本轮支持保留固定小时对照，不支持定期在这24套里追逐近期赢家。

## PAXG：12周窗口的价值主要是减少不合适时期的交易

12周窗口、每1/2/4周检查，全期分别+36.94%、+51.89%、+45.72%；其余2、4、8周共9种全部亏损。全期最高的12周＋2周在2,082天中有938天空仓，2021年完全空仓，避开固定小时版当年−55.00%。后两年+85.15%，与固定版+85.28%接近，因此不能把全期改善说成每个后续时期都交易得更好。

这里存在一个明确的解释限制：过去2周时，小时候选只有5.2%的检查记录达到20笔交易门槛；4周为49.1%，8周96.5%，12周100%。因此“12周好”同时包含了小时级别终于有资格参加选择的影响，不能全部归因于更长窗口能识别趋势。20笔门槛没有在看到结果后改变。

较早年份选出的是12周＋1周，该办法当时仍亏16.26%，只是12种里亏得最少；后两年+63.53%，低于固定版+85.28%。不能将它描述成早期已经证明有优势。

## ZEC：这12种短窗口选择没有改善原策略

固定小时参数全期+81.58%、后两年+429.37%；12种短窗口方法全期全部亏损，最好的也亏76.24%。原小时策略仍有82.13%的历史最大回撤，本轮没有把它变成稳定盈利策略。

较早年份12种中亏得最少的是4周＋1周，当时−79.31%，后来两年又−55.71%。它只是用于按预定规则比较，不是当时应当采用的交易建议。停止在本轮结果上继续加窗口来挽救ZEC的短窗口选参说法。

## 必须收窄此前的结论

此前固定原小时参数在2023年10月之后四币都赚钱，但把更早年份加回来，PAXG全期为−63.28%。所以“固定小时版本”是统一比较基准，不应再称为四币长期都有效的版本。

本轮与旧三年／半年方案不只观察窗口不同：旧方案还选择初始止损、利润保护，并在每半年统一清仓。因此不能直接相减就声称变化完全来自观察长度。所有版本、原始逐笔、每次选择和数据哈希保留；四个固定对照与未改动的原引擎逐笔、信号、权益、报告完全一致。
