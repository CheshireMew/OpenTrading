# 本轮机制检验结论

2020-10-01至2026-09-10，后两年从2024-09-10起。ETH、BTC、PAXG、ZEC各自固定15分钟或1小时，不互相切换。12种规则在开跑前冻结，无收益排名参与决策。96个回测完成，8个原版控制与原项目引擎完全一致。历史已经研究过，不称为全新样本。

## 灵敏度是部分原因，不是完整解释

PAXG 15分钟只把突破0.4W扩大到1.2W：交易10782降至3769，快速反向亏损3299降至204，全期−99.98%改善为−94.71%，后两年−45.21%改善为−3.82%。但一笔平均赚0.759%、平均亏0.348%，907个赢家对应2803个输家，仍未形成正的平均单笔收益。只放慢到EMA89，全期−99.88%、后两年−48.42%，没有解决。

ZEC 15分钟只加宽门槛：快速反向亏损1234降至12，反向亏损3349降至385，但固定止损亏损4897增至5111；总交易11756降至8174，平均一次亏损从0.816%扩大到0.970%。全期仍亏96.18%，后两年却赚251.25%。说明改动对不同阶段差别很大，也说明降低反向退出频率可以把损失转移到初始止损，而非消除损失。

## 三项直接自适应不是通用修复

自动均线(ER31线性插值EMA21—89)、波动初始止损2ATR与启动4ATR、启动后回撤2ATR的保护全部开启：PAXG15m全期−99.99%、1h−78.56%；ZEC15m−99.97%、1h−93.11%。ETH与BTC也未普遍改善。该结果否定本轮这些具体公式，不等于所有自适应公式都无效。

所有数字、ER窗口、快慢边界及倍数均预先固定。它们直接从历史价格计算，不根据过去P&L选参数；这并不意味着公式没有人为设定或不会过拟合。自动均线不是标准KAMA的平方因子公式。

## ZEC转正包含入场时机和保护启动路径的改变

ZEC15m过滤版与原版共同入场861笔，组内复利仍为−23.45%；过滤后新出现361笔，组内复利+69.10%。共有交易的退出时刻及价格逐笔相同。过滤历史信号改变是否已有持仓，使原来忽略的同方向信号成为新的入场，因此不是简单从旧交易列表剔除亏损。

具体例子(UTC)：2026-02-13 08:45，原版233.44做多；最高到238.23，超过其2%启动价238.1088；13:45开盘235.26退出，+0.7796%。过滤版12:30才以233.71做多，它的2%启动价238.3842尚未达到，因此没有被同一保护线退出，最终2026-02-15 06:45在312.14反向退出，+33.5587%。该例来自已保存交易，不能推断以后都应延迟入场；它说明一个很小的入场价差通过保护启动条件，能造成很大的持仓结果差异。

## 尚不满足稳定性要求

PAXG1h过滤版2021—2024年分别−4.41%、−6.95%、−1.80%、−1.87%；2025+11.64%，2026截至9月10日+18.40%。五个完整年份仅一个盈利；将最好的两笔赢家收益归零就不再盈利。

ZEC15m原版加过滤：2021+12.04%、2022+8.87%、2023−14.86%、2024+13.94%、2025+19.96%、2026部分−5.95%。全期最大回撤29.78%，持仓中位1.5小时。将最佳月份2026-02的+42.15%归零，全期为−8.94%。

ZEC15m三项自适应再加过滤：全期+67.58%、前段+30.79%、后两年+28.13%；1208笔，335赢、863亏、10保本，胜率27.73%，最大回撤45.92%，持仓中位2.75小时。将最佳月份2025-10的+73.56%归零，全期为−3.44%。这些归零只是算术集中度检查，不是可执行交易规则，也不说明依赖趋势赢家本身错误；但现有净利润余量较薄。

保留入场选择性这一研究线索；不宣称已找到跨标的通用规则，也不继续在本轮结果上加门槛寻找更高冠军。旧策略、源码与结果没有覆盖。原版同一小时策略本轮与上轮数值不同，是起点2020-10-01而非2020-12-28，不能混成同一期间比较。
