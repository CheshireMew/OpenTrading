# 原EMA55、15分钟：亏损原因的本轮结论

本轮复用项目已有的31,866笔交易：PAXG 10,782笔，ZEC 11,756笔，ETH 9,328笔。区间为2020-10-01至2026-09-10。不改交易规则，不重新选择参数，不计手续费和滑点。

## PAXG：原入场规则抓到的短期顺向空间不足

8,624笔有完整4小时观察记录的亏损交易中，8,602笔（99.74%）从入场算起4小时内没有达到原来的2%保护门槛。这个数字受PAXG波动较小影响，不能独立证明入场差。因此另用每次入场前计算的ATR统一尺度：仍有78.69%的亏损单没有走到2倍ATR的顺向目标。

再把赢家也算进来：全部入场中，4小时后价格顺着入场方向的比例为38.79%；在反向1倍ATR之前先达到顺向2倍ATR的比例为18.55%，低于ETH的31.14%。这说明在本轮固定窗口下，原入场规则在PAXG上捕捉的顺向机会较少。不能把大多数亏损归结为已经赚了很多但利润保护没做好，也不能据此断言更久以后没有行情。

## ZEC：有顺向行情，但平均亏损更大

|标的|交易数|胜率|平均盈利单收益|平均亏损单收益|
|---|---:|---:|---:|---:|
|PAXG|10,782|16.20%|+0.51%|−0.20%|
|ZEC|11,756|28.84%|+1.85%|−0.82%|
|ETH|9,328|26.93%|+1.83%|−0.58%|

ZEC胜率略高于ETH，赢家平均收益也相近，但亏一笔平均损失比ETH大约42%。按每笔固定100元估算100笔，ZEC赢家贡献53.36元、输家消耗57.37元，净亏4.01元；ETH分别为49.15元、42.06元，净赚7.09元。这是解释盈亏结构的等额投入例子，不是复投账户收益。

全部ZEC入场中，4小时内在触及反向1%之前先走到顺向2%的比例为23.00%，高于ETH的15.12%；统一成2ATR/1ATR后为29.61%，也接近ETH的31.14%。因此“ZEC没有行情”不能解释结果。

ZEC亏损样本中，4小时内没有到顺向2%的有7,215笔（87.34%）；先越过反向1%才到顺向2%的有904笔（10.94%）；先到顺向2%但发生在实际退出后的有85笔（1.03%）。不能把先跌穿风险线后又反弹，直接当作应当继续持有的证据。该分解也没有证明退出规则已经最优，尤其不能解释所有持有较久的大赢家。

## 入场前能不能提前区分？这三条标准没有稳定做到

事先固定的三个检查：此前价格走得较顺（ER31至少0.2）；此前4小时买卖方向切换少于2次；1%止损至少容纳入场前1倍ATR。没有在看到结果后更换门槛或组合。

PAXG和ZEC均没有一条检查，在2024-09-10前后两段同时留下平均盈利、且优于另一组的交易。尤其“此前切换少，应该更好”在两段均没有占优。放宽到分年看，也未达到预定的一致性要求。ETH同样没有特征通过所有要求，其中止损/ATR检查在后段另一组只有75笔，样本不足；不能把“不通过”统一解释成确定无效。

这些是对原版交易的分组诊断，不是过滤后策略收益。过滤会改变后续入场时机；之前ZEC过滤版转正与本轮分组未发现稳定优势可以同时成立，旧版本仍保留。

## 本轮决定

停止继续搜索原15分钟策略在PAXG、ZEC上的补救参数：目前已看清不同标的的盈亏结构差异，但尚未找到可重复的事前入场改进依据。此前转正的探索版本不删除，也不升级为已证实稳定的策略。ETH保留为原策略对照。

这个决定仅针对当前策略、周期和研究路线，不是否定所有趋势交易。所有历史已经研究过，前后分段和逐年检查都不能叫从未见过的验证。
