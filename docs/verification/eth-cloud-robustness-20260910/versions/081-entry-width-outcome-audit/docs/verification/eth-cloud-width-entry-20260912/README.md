宽度与收益并非越宽越好：较宽组表现较好，但极宽组初始止损占比很高；最窄组整体也为正，不能据此断言应该完全禁掉窄幅入场。原策略固定1%止损与不同波动幅度的匹配值得后续检验，但当前分组不能单独证明因果。各年和多空分组保存在完整JSON中，不同组处于不同历史行情，存在时期混杂。
