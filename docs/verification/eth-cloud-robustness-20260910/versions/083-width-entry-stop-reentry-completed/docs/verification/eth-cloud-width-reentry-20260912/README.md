## 每个问题的结论

只取消不追远处限制，六年收益从 +25,829.05% 降到 +25,057.90%，交易从 9,427 增到 9,656。没有提高收益，本次保留原限制。

固定外线突破入场只有 +620.59%；交易降到 4,783 笔、胜率升到 32.78%，但收益远低于原版。与同样取消追价限制的 +25,057.90% 对照相比也明显更差。要求突破更远改变了入场及反向退出时机，不能把少交易等同于过滤掉亏损。

窄时外线、宽时原规则：使用原通道宽度收益 +3,740.97%，使用布林宽度 +2,388.71%，都低于原版。交易减少、胜率提高，却没有增加收益。本次不采用这套宽窄切换规则。

只改随宽度止损，六年收益 +21,783.18%，低于原版。初始止损次数反而由 1,927 增至 2,003。匹配的 1,884 笔原初始止损交易中，29 笔改后盈利，但 763 笔亏得更多；其余还包括减亏和不变。逐年并非都差：2024、2025、2026 部分年份有所改善，但 2021 从 +821.01% 降至 +683.99%，2023 从 -1.66% 变成 -10.82%。本次规则没有增加总收益。

原版只加初始止损后补一次，保留了全部原版入场及退出表现，新增 35 笔：8 赢、27 亏，平均每笔 -0.37%；六年收益降为 +22,592.41%。持仓期间重复同向信号为 0。9 月 11 日的实例确实由 20:45 补仓接回行情、赚 +3.45%，但实例成功不代表六年整体改善。组合版的 427 笔补仓平均略赚 +0.018%，因此不能说补仓在任何环境都无效。

随宽度止损加补仓收益 +18,497.21%；再加通道宽窄入场切换，只有 +2,207.91%。八个改版没有一个超过原版。若按本次六年总收益决定，现在保留原版，不把这套组合替换进手工交易 Pine；此轮停止，不继续按结果细调阈值。

随宽度止损使用相对最近一天的宽度，限制为 0.5%～2%；持续高波动很多天后，参照也升高。它不代表已经验证了所有波动止损或 ATR 止损方法。
