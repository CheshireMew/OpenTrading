## 结论

不限根数、等收盘突破信号收盘价：六年收益 +3,322.27%，低于原版 +25,829.05%；交易从 9,427 降到 6,983，胜率从 26.94% 升到 28.03%。少做了交易，但收益没有改善。原版 2,541 个亏损信号和 125 个盈利信号没有被用于新版本入场；在双方都交易的同一信号中，580 笔由赚变亏，58 笔由亏变赚。可见确认避开了一批旧亏损，但延后入场的代价抵消了这个好处。

不限根数、等收盘突破信号最高／最低价：六年收益 +899.38%，6,224 笔，胜率 28.25%。平均等待 4.26 根 K 线；同一信号原本盈利、改后亏损有 752 笔，反过来只有 63 笔。确认更严格没有带来更高收益，最大回撤也从原版 33.05% 增到 43.72%。

只允许第 2 或第 3 根收盘突破信号实体：六年收益 +1,617.56%，6,133 笔，胜率 27.31%。交易最少，但收益仍远低于原版。该版本有 4,086 次等待到期；没用于入场的原版信号中，802 个原本赚钱、3,660 个原本亏损。它没有实现少交易同时提高总收益。

已按要求实现记住首次信号、反向信号取消并重记、后续收盘确认、一次信号仅开一次仓、持仓不重复同向入场。三个版本的 19,340 笔交易逐笔检查通过。不限根数的收盘价版平均等 2.81 根、最长 95 根；最高最低价版平均等 4.26 根、最长 103 根。确认收盘仍须满足原 2 倍振幅的追价上限，反向平旧仓不延后。三个版本都没有超过原版，本轮保留原版，不再扩展参数搜索。

按相同原信号配对，收盘确认版有 6,761 笔可比较，其中 6,746 笔入场价更不利（做多更高、做空更低）。平均价差约 0.291%；这批交易原本平均每笔赚 0.310%，延后入场后平均赚 0.068%。这不是手续费，而是等待价格确认付出的成交价差；退出时机、止损和利润保护也会随入场改变，不能把全部收益差直接归因于这个价差。全仓复利进一步放大了长期累计结果的差距。[配对记录](entry-price-attribution.json)。
