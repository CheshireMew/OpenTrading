中心 EMA(hl2,55)，宽度 W=EMA(high-low,31)，原始信号为收盘穿过中心 ±0.4W。原本距离超过 2W 的入场信号不合格，不据此积累；但任何原始反向穿越仍然取消旧等待并平持仓。

原合格入场信号先记录该根 K 线及方向，不立即开仓。等待期间同方向信号不替换最初那根；反方向原始信号取消旧等待，若新信号合格，就记录新的方向及 K 线。持仓期间不记录同方向新信号。信号确认成功后消费一次，止损后不复用；此轮没有自动补仓。

三个版本：

1. 不限等待根数：后续收盘高于信号收盘价才做多，低于信号收盘价才做空。
2. 不限等待根数：后续收盘高于信号最高价才做多，低于信号最低价才做空。影线仅用于定义被突破的价位；盘中刺破而收盘收回不算确认。
3. 信号 K 线算第 1 根，仅第 2 或第 3 根可确认：后续收盘超过信号实体上沿才做多，跌破实体下沿才做空；没有确认就过期，等待新的合格原信号。

确认必须来自之后的 K 线，不能信号当根确认。确认收盘还须在当前通道相应方向，且仍满足原来不超过 2W 的追价限制。超远则继续等；有限根数版仍受原到期时间限制。没有增加成交量、动量或其他过滤。这里保留了追价限制，不是“无论价格多远都追入”。

旧仓的反向平仓保持原时机，下一实际 K 线开盘平仓；新反向仓另等确认。初始 1% 止损、浮盈 2% 启动且允许回吐最高浮盈 50% 的利润保护均保留。开仓在确认后的下一实际开盘执行，初始止损从成交价计算且开仓当根有效。保护线只用已完成 K 线更新，下一根才有效。

有限根数版与收盘不限根数版同时改变了确认价位和等待期限，不把两者差异全部解释成期限的影响。
