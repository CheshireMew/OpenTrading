# ZEC 七年：入场确认有帮助，取消固定止损反而拖累

本次改的是此前完整七年收益最高的原EMA通道版本：ZEC/USDT、30分钟、EMA144。最近两年收益最高的EMA55不是这一个：EMA55最近两年+1,056.97%，相同七年只有+15.64%；EMA144七年+125.86%。范围在本次运行前已按用户纠正，不再测试两年冠军。

四组统一为2019年9月10日至2026年9月10日，使用同一份币安现货价格数据模拟多空，每笔当时全部资金复投，不加杠杆，不计手续费和滑点。

| 版本 | 七年累计收益 | 总交易 | 赚钱 | 亏钱 | 持平 | 胜率 | 最大回撤 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 原版：直接入场＋1%止损 | +125.86% | 4706 | 2206 | 2479 | 21 | 46.88% | 50.87% |
| 只改入场：第2或第3根盘中突破实体＋1%止损 | +364.30% | 4445 | 2132 | 2310 | 3 | 47.96% | 42.14% |
| 只取消固定止损：原入场 | +43.84% | 3440 | 2412 | 1009 | 19 | 70.12% | 84.77% |
| 两项一起改：盘中确认＋取消固定止损 | +198.29% | 3244 | 2313 | 929 | 2 | 71.30% | 82.33% |

保留1%止损，只加第2或第3根盘中突破信号实体确认，七年收益从+125.86%变为+364.30%。交易从4706笔减少到4445笔，胜率从46.88%提高到47.96%。本次有帮助。

原入场不动，只取消固定止损，七年收益降到+43.84%。胜率升到70.12%，但平均亏损单从-0.98%扩大到-2.66%，最大回撤从50.87%扩大到84.77%。本次不应取消固定止损。

两项一起改的七年收益是+198.29%，超过原版，低于只改入场。无论是否保留止损，盘中确认都提高本次收益；无论是否加确认，取消固定止损都降低本次收益。改善来自入场确认，取消固定止损拖累结果。

原参数保持为：高低中价EMA144，振幅为每根高低差的EMA31，中心线±1.2倍振幅产生原入场信号，距离超过3倍振幅不追。浮盈达到1%开始保护，允许回吐最高浮盈35%。固定止损开关分别为1%或关闭。

新确认规则：原信号所在K线算第1根，只允许第2或第3根盘中突破该信号实体。做多突破实体上沿，做空突破实体下沿，不用等收盘。未成交遇到反向信号就取消原等待，按新方向重新计数。持同向仓不重复开仓；反向平仓仍按原收盘信号、下一根开盘执行，不等待反向入场确认。确认还保留原通道方向和不追价限制，详细成交价规则见RULES.md。

只改入场的版本在2026年仍亏28.45%，不能把七年总收益改善说成每年稳定盈利。

已核对两种确认版共7689笔，每个原信号最多成交一次，且只在信号后的第1或第2根成交（把信号本身算第1根，就是第2或第3根）。两个取消止损版本的初始止损退出均为0，利润保护和反向退出仍实际发生。保留止损的盘中确认版有252笔同根先后不明，全部按入场后再触发止损计入，未挑有利顺序。

原版与旧存档的4706笔交易、全部信号、逐根权益和汇总完全一致。新旧策略均保留；28项相关测试通过。为使用项目公开回测入口，将已有研究数据对应的ZEC/USDT补入币种目录；未改变数据源或下载新行情。
