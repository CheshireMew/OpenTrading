# ZEC EMA144：只加盘中确认、保留1%止损，亏损来自哪里

结论：大部分亏损发生在利润保护启动之前，由1%固定止损退出。实体突破确认能改善七年整体结果，但仍不能保证突破后价格持续朝入场方向走，也不能保证价格不会先回撤1%。反向平仓不是该版本亏损的主要出口。

本次只读取原有回测，没有修改策略或新增回测。对象是 ZEC/USDT 30分钟，2019-09-10至2026-09-10，运行 `2a0c67e629a77db26e664880bab12d44`。EMA144、振幅EMA31、门槛1.2W、不追3W、浮盈1%启动保护、回吐35%、初始止损1%，信号后两根盘中突破实体。4445笔交易，2132盈利、2310亏损、3持平，累计收益364.30%。沿用全仓复利且不计手续费滑点的约定。

| 亏损退出方式 | 次数 | 占全部亏损单 | 该类平均单笔亏损 |
|---|---:|---:|---:|
| 初始1%止损 | 2213 | 95.80% | 1.0002% |
| 利润保护退出但最终亏损 | 89 | 3.85% | 0.3134% |
| 反向信号平仓 | 8 | 0.35% | 0.8838% |

固定止损占实际亏损金额的98.60%；如果统一各笔本金，按亏损百分比求和，占98.44%。这里统计的是所有亏损单的损失，不是净收益，不能把累计复投下的总亏损金额直接当成账户回撤。初始止损的10笔按开盘跳价退出，其余2203笔按盘中止损价退出，所以平均损失略超过1%。

## 入场后的反向波动来得很快

2213笔固定止损里，709笔在入场那根30分钟K线内退出，1155笔在入场K线或紧随的一根内退出。709笔中，252笔只有OHLC、无法确定不利极值是否发生在突破入场前，按已固定的保守顺序算作入场后止损；另457笔有开盘成交或收盘穿过止损的证据。不能把252笔直接认定为实盘必然发生的止损。

其余1504笔是在更晚的K线止损。其中916笔在退出前已经完成的K线里，最高浮盈仍不足0.5%；588笔曾达到0.5%但未到1%。它们都没有启动利润保护。这支持“很多突破后续推动不足”的描述，但不能从30分钟OHLC确认退出K线内部曾否短暂先涨后跌。

“触发止损”是退出方式；背后的价格路径既可能是短暂突破后反向，也可能是短暂回撤后继续原方向。两种情况都存在，不能把所有固定止损都当成假突破或误伤。

## 扫掉后恢复存在，但直接取消止损也会放大真亏损

读取此前已经完成的“盘中确认、取消固定止损”运行 `a3f988c546a7d514c979ba0f4c98fca2`，只匹配入场时间、方向、价格完全相同的交易。在1623笔可匹配固定止损单里：769笔后来变为盈利，770笔亏得更多，83笔仍亏但没有扩大，1笔持平。获救盈利单平均赚1.18%，亏损扩大的一组平均亏3.13%。

另590笔固定止损单找不到完全相同的入场，因为取消止损后持仓时间变长，也改变了后续交易机会。不能把这个配对直接当成全部交易的独立过滤实验。完整回测已有明确对照：保留止损赚364.30%，取消止损赚198.29%；因此“存在被扫后恢复的单子”不足以支持直接取消止损。

在固定止损那根K线收盘时，有129笔价格已经回到原入场价的盈利一侧；排除252笔同根先后不明案例后，仍有71笔。这只是事后观察到的回升，不能据此承诺重新入场一定盈利。

## 波动过大、过小都较弱，尚不能用来直接过滤

用入场委托发出时已经收盘的K线计算振幅比例：W是每根高低差的EMA31，比例为W/价格，并非通道上下总宽度。固定分组仅为描述，没有寻找最优阈值。

| 平滑振幅占价格比例 | 交易数 | 亏损数 | 胜率 | 平均每笔收益 |
|---|---:|---:|---:|---:|
| 不足0.5% | 192 | 104 | 45.83% | -0.0376% |
| 0.5%至不足1% | 1954 | 963 | 50.67% | +0.0636% |
| 达到1% | 2299 | 1243 | 45.85% | +0.0323% |

当平滑振幅已经达到价格的1%，固定1%止损不大于一根K线的平滑高低差，容易被短期价格摆动碰到。这是一个有依据的解释方向，但高波动组仍有正的平均收益，不能据此断言应排除它，也没有验证扩大止损是否更好。低波动组同样较弱，“波动越大越好”或“越小越好”都不符合这里的分组结果。

另一个入场前可观察的关系是中心线方向：过去6根（3小时）中心线运动与开仓同向的3802笔，胜率48.68%；相反或持平的637笔，胜率43.96%。6笔因窗口开始或数据空档不归类。这只能说明同向组表现相对较好；同向组仍有1948笔亏损，不足以构成可靠的亏损识别规则。

## 89笔利润保护亏损来自保护的生效时点

模型在K线收盘后，根据该根最高/最低价更新保护线，下一根才生效。89笔全部在下一根开盘退出，且前一根收盘时，价格已经越过新计算的保护线。78笔前一根收盘时已经浮亏，另11笔前一根收盘尚未亏，下一开盘变成亏损。这89处相邻K线均无历史数据缺口，不能简单解释成缺K线或全部是突然跳空。

例如2019-09-30 15:00 UTC做多，入场38.53，后来最高39.00，按规则新保护价应为38.8355；但产生这个高点的K线已回落收于38.29，新保护价还没有生效。下一根开盘38.31退出，最终亏0.57%。这是当前“收盘更新、下一根生效”的回测规则产生的延迟，不能声称在38.8355已经成交后仍然亏损。完整例子及K线保存在 `profit-protection-example.json`。

多单2291笔，亏1196笔，胜率47.71%；空单2154笔，亏1114笔，胜率48.24%。两个方向的胜率接近，并不是主要由空单拖累。

全部结论是对已见历史的描述。当前可以确定入场后短期反向波动与1%止损的关系、保护延迟的具体机械原因，以及多空并没有明显悬殊；尚不能把这些事后分类当成能提前识别亏损的规则。
