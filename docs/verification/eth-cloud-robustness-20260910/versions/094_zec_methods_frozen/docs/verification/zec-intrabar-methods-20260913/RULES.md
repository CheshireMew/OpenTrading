# 固定七次新运行，逐项检查提出的优化方法

原版为 ZEC/USDT 30分钟、2019-09-10至2026-09-10：EMA(hl2,144)、W=EMA(high-low,31)、原门槛1.2W、不追3W；信号K线为第一根，仅第二或第三根盘中突破实体才进；1%初始止损；浮盈1%启动保护，最高浮盈回吐35%；原反向信号收盘确认，下一实际开盘平仓。原版累计364.2994%，运行2a0c67e629a77db26e664880bab12d44，保留不覆盖。

1. 整根突破：只将实体上/下沿改为原信号最高/最低价；仍限后两根，仍不追3W。
2. 中心方向：只加过去6根实际观测K线的中心线方向过滤。多单要求中心线上升，空单要求下降；信号记录和每次挂委托都检查，原反向平仓不被过滤。
3. 振幅止损：初始百分比=1.5×W/挂委托时收盘价×100，限制0.5%至2%。实际入场价据此确定止损，开仓后不外移。只替换初始1%止损，利润保护不动。
4. ATR止损：与上一条相同，但使用ATR14（真实波幅，首14根平均种子，然后Wilder平滑）。倍数仍1.5、上下限仍0.5%/2%，不优化倍数。
5. 单次重进：只有初始止损之后才开启重进等待。到止损所属30分钟K线收盘才知道完整极值；下一根起做多需突破该根最高价、做空需跌破最低价，同时保留当前通道方向与3W追价上限。重进不限等待根数，原反向信号立即取消资格。每个原信号最多正常入场一次、重进一次；止损后第二次失败不再重进；持仓不重复发单。
6. 细周期成交对照：仍用原版30分钟信号和30分钟更新保护，只在成交路径上使用项目已有5分钟行情。
7. 更快保护：与第6组完全相同的5分钟成交行情，仅将保护价更新从30分钟收盘改为每5分钟收盘，下一根5分钟生效。不是逐笔实时保护；仍不能确定一根5分钟K线内部的全部先后。

前5组单独与原版比较；第7组必须与第6组比较，分开“细化成交数据”和“改变保护频率”两个因素。不组合获胜因素，不按结果换阈值，不增加新的标的或时间范围。

数据由项目原有快照提供。细周期只接受6根完整5分钟K线、且聚合OHLC与原30分钟一致的区间。原30分钟122654根中，122354根可匹配；292根OHLC不匹配、8根不完整，两个细周期版本都在这300根上退回原30分钟执行，不补造价格或擅自更改信号K线。全部不匹配和原始数据均保留。历史原30分钟缺口继续按原规则保留，不插值。

细周期委托在下一根30分钟内持续等待触发，只能成交一次，期末未触发自动作废。出现细周期跳价以实际开盘成交，越过追价上限后该30分钟委托作废，不假定中途回落可以补成交。初始止损持续生效，同一细K线入场和止损顺序不明按保守顺序，并单独计数。更快保护只使用已经完成的细K线极值，绝不先用某根最终高点抬升该根早先的保护价。
