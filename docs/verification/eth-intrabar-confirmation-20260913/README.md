## 结论

突破信号收盘价就入场：同根先后不明也算止损时，六年收益 +54,411.30%，高于等收盘的 +3,322.27% 和原版 +25,829.05%。交易 9,288 笔，2,540 笔赚、6,747 笔亏、1 笔持平；胜率 27.35%，最大回撤 28.98%，原版为 33.05%。按同一原信号配对，141 个原版入场信号没有被用于新版，其中 139 个原本亏、2 个原本赚；9,286 笔双方都做的交易中，9,152 笔仍在原来的那根 K 线入场。与等收盘相比，它避免普遍晚一根成交，并避开了少量原本亏损的信号。这个版本值得保留为后续检验候选。

突破信号最高／最低价就入场：同根先后不明算止损时，六年收益 +14,941.19%，高于等收盘的 +899.38%，但低于原版；7,952 笔、胜率 27.87%、最大回撤 42.80%。另一种先后假设却达到 +73,840.07%。这个版本对入场当根影线顺序非常敏感，目前不能确定它是否超过原版，不能挑较高的数字当作结论。

仅第2或第3根盘中突破信号实体：同根先后不明算止损时，收益 +54,455.55%，高于等收盘的 +1,617.56% 和原版；9,288 笔、2,537 笔赚、6,750 笔亏、1 笔持平，胜率 27.31%。另一顺序假设为 +77,954.61%。9,288 笔中有 9,221 笔就在信号后的第一根成交，所以两根期限通常没有起到延迟作用，成绩与不限根数的收盘价突破版非常接近；不足以认定限制两根更好。

六个盘中对照的 52,998 笔交易全部完成逐笔检查：先记录信号，后续 K 线才可成交；触发价、追价上限均提前确定；没有跨已收盘的反向信号继续用旧信号，也没有重复使用同一信号开仓。开盘跳过触发价用实际开盘，不回填更好价格。原版在新增委托功能后，全部交易、信号、成交、权益和保护线重放一致。此轮保留收盘价盘中突破及两根实体突破候选，暂不确认最高最低价版优于原版；结束本次测试。
