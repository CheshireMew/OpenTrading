# 原信号积累后，盘中突破即入场

使用原项目保存的 Binance ETH/USDT 15 分钟行情，2020-09-10 至 2026-09-10 UTC，650 根预热和原时间缺口。每笔投入当时全部资金，盈亏复利，不计手续费、滑点。历史已经看过，此轮是规则对照。

保留中心 EMA(hl2,55)、W=EMA(high-low,31)、原收盘穿越中心±0.4W的信号、2W不追远处、1%初始止损、浮盈2%启动并允许回吐最高浮盈50%的保护。原反向信号仍在下一实际开盘平旧仓。保护线在收盘更新、下一根生效。

先记住合格原信号及该根价位，同方向信号不替换，反向信号取消旧等待并按新方向重记。原信号产生当根不得入场；从下一根起提前挂突破委托，盘中触发即成交，不再等待收盘。成交后一次消费，包括开仓当根就止损；持仓不重复同向入场。本轮不另加止损后补仓。

三个价位与上轮对应：不限根数突破信号收盘价；不限根数突破信号最高／最低价；信号算第1根，只在第2或第3根突破信号实体上／下沿。突破采用严格越过：以0.01为本轮价格单位，多单高一个单位、空单低一个单位。

每根收盘后，用已知的中心线和宽度确定下一根的有效价位。入场仍须在通道同向外侧且不超2W：多单触发价是信号价位与已知内侧上沿中较高者的下一个价格单位；空单对称。这样不会用入场这根尚未完成的最高、最低、收盘反算通道。相较旧版在确认收盘检查距离，新版只能使用上一收盘已知通道，这是改为真实盘中委托所必需的时间差异。

委托只对下一根有效，未触发则收盘按同一记忆重挂；有限根数版本在第二个等待根结束后过期。如果开盘已越过触发价，按实际开盘成交；若同时跳过追价上限，这一根取消委托，收盘仍可按未过期记忆重挂。若触发价本身超过追价上限则不挂单。退出旧仓和新方向突破委托可以并存：先在开盘平旧仓，新方向在本根突破才入场。

## 入场当根的先后顺序

15分钟OHLC无法确定影线先后。仅对盘中入场后，同根极值碰到初始止损、但收盘又在止损有利一侧的交易，保存两种执行假设：

- 假设0：算先入场再触发止损，作为较保守的结果。
- 假设1：算不利极值在入场前发生，之后才突破入场，本根不据这个极值止损。

如果入场根最终收在止损不利一侧，就必然曾在入场后越过止损，两种假设均止损。开盘成交之后的全部极值都在入场后，不允许忽略。未明确先后的交易在最终逐笔中标记 `entry_bar_ambiguous`。两种假设分别运行完整账户，会影响后续持仓与交易，不能称它们为账户收益的严格上下界，也不把更高的结果当作已证实收益。未使用逐笔或1分钟行情。
