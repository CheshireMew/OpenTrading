写代码前记录原项目策略文件、完整参数、时间区间及原始结果位置。核对价格输入、振幅算法、信号形成时间、成交确认方式、反向退出、止损、保护更新周期、信号过期及是否重进。禁止只把EMA参数填进旧Pine，然后称为同一个策略。

本次参数：15分钟；EMA(hl2,55)；EMA(high-low,31)，不是ATR；门槛0.4倍、不追2倍；仅原信号后两根K线盘中突破信号实体及最新门槛；价格单位0.01；固定1%止损；浮盈2%启动保护、回吐50%；5分钟收盘更新保护，下一根生效；原反向信号下一开盘平仓；不自动止损重进。

## 标签必须清楚

| 操作 | 标签文字 | 颜色 | 默认位置 |
| --- | --- | --- | --- |
| 开多 | 做多 | 红 #F23645 | K线下方 |
| 开空 | 做空 | 绿 #4CAF50 | K线上方 |
| 反向信号平多 | 平多 | 紫 #9C27B0 | K线上方 |
| 反向信号平空 | 平空 | 青 #00838F | K线下方 |
| 固定止损 | 止损 | 橙 #FF9800 | 多仓上方、空仓下方 |
| 利润保护退出 | 保盈 | 金褐 #B8860B | 多仓上方、空仓下方 |

平空后开多，显示“平空”和“做多”两个标签；平多后开空，显示“平多”和“做空”。只有实际模拟开仓成功才显示做多/做空；反向平仓后可能因未突破或超过追价上限而不新开仓，不能把它写成已反手。

同根多事件按发生顺序排列，以上下独立的计数器逐层增加间距，不能多次贴在同一坐标。颜色固定表达操作，不随本笔盈亏变化。时间、方向、模拟成交价放悬停提示，不把数量、金额、订单ID、长句堆在标签上。缩到很小或相邻K线很多时，无法保证任何缩放下都不重叠；提供标签间距和保留数量调整，不通过隐藏亏损交易制造整洁假象。

## 通道保持原样

默认只画灰色中心线、绿色上突破线、红色下突破线、淡云带、可关闭的外围中心±2倍平滑振幅。显示云带填充采用内侧突破线间区域，属于界面表现，不改入场公式。不画红色/橙色直角止损线，不画开仓连线，不加背景染色、巨型状态表、收益宣传文字。持仓、待入场价、不追价边界、止损/保护价放数据窗口，默认不在顶部指标状态栏堆数字。

手工观察版本优先用indicator及自定义事件标签，从源头避免TradingView策略原生箭头、订单数量和文字与自定义标签重复。若另交strategy版本，必须说明如何关闭原生交易显示，并核对成交算法差异；不能为了回测面板而牺牲本次手工图表的清晰度。

## 时间、数据与实时行为必须如实说明

原信号只在15分钟收盘确定；后续两根的委托使用前一收盘已知价位；反向信号取消旧等待；过期不继续触发；成交后消费信号；持仓期间不重复开同向仓。固定止损与反向平仓、利润保护同时保留，新保护价不追溯作用到产生该保护价之前的价格。

本次代码 `strategies/pine/eth_ema55_confirmed_manual_v6.pine` 在15分钟图上顺序处理已完成5分钟数据。历史成交标签用于复盘，实时标签也是5分钟确认记录，可能比实际触价晚最多约5分钟及行情延迟。不能把该标签提醒当成精确的即时市价下单指令。需要手工执行时，提前参考数据窗口“下根突破触发价/不追价边界”，可启用下一根条件单价位提醒；价格失效或过期后必须撤销手工委托，脚本不会替用户撤单或管理实际账户。

不使用当前未收盘15分钟信号提前决策；不通过lookahead偷看未来；不将完整5分钟高低点的历史推断说成已知逐笔顺序。同根触发入场与止损采用项目保守口径，仍可能与实际路径不同。

缺少完整5分钟数据的历史段暂停交易重建并重置模拟持仓，不以15分钟保护伪装成相同规则；恢复后从新信号开始。这一处理和原项目少量空档回退不同，不能宣称逐笔完全一致。TradingView细周期历史有覆盖上限，且可能有数据源修订，见[官方跨周期数据文档](https://www.tradingview.com/pine-script-docs/concepts/other-timeframes-and-data/)。Bybit永续与原项目Binance现货不是同一价格源；可用预热和起点也不同，不能承诺界面重现项目+64,338.16%。
