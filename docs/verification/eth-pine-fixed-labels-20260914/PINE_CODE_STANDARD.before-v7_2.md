## 规则和显示分开处理

保留EMA(hl2,55)、EMA(high-low,31)、0.4倍突破门槛、2倍不追价边界、信号后第2/3根盘中突破实体确认、固定1%止损、浮盈2%启动保护、回吐50%、反向信号下一根退出。振幅不是ATR。持仓期间不重复同向入场，成交消费信号，旧信号超过两根或出现反向信号即失效。

本次明确改变的是保护更新周期：15分钟收盘计算新保护价，下一根起有效。固定止损和已经生效的保护价仍可盘中触发。禁止重新加入5分钟数据、5分钟成交确认或5分钟利润保护。改变显示时不得顺便改变入场或退出规则。

原项目+64,338.16%记录来自 `docs/verification/eth-intrabar-short-window-20260913/policies/fixed.json`，使用5分钟更新保护。本次按用户要求改变了这条规则，没有重新回测，不得称v7已复现同一收益。

## 标签沿用原来的意思

| 动作 | 文字 | 颜色 |
| --- | --- | --- |
| 开多 | 做多 | 红 #F23645 |
| 开空 | 做空 | 绿 #4CAF50 |
| 平空并开多 | 平仓做多 | 红 #F23645，与做多相同 |
| 平多并开空 | 平仓做空 | 绿 #4CAF50，与做空相同 |
| 只平多，没有开空 | 平多 | 玫红 #E91E63 |
| 只平空，没有开多 | 平空 | 青绿 #00897B |
| 止损或利润保护退出 | 止损 | 橙 #FF9800 |

做多与平仓做多统一红色，做空与平仓做空统一绿色。恢复v5的文字含义，不再额外加“保盈”等标签。反手的两个方向必须文字、颜色均可区分，不能都写“平仓反向”或共用蓝色。实际只平仓时不得标成已经反手。止损后开新仓不冒称反手。

开多放K线下方，开空放上方，止损向上留出间距。不叠加原生成交箭头、订单数量、长段说明、状态表。历史同根确有模拟入场和止损时仍保留两个事件，不能仅为整洁隐藏亏损。

通道保留灰色中心线、绿色上门槛、红色下门槛、淡云带和可关闭的外围±2倍振幅。不画红橙直角止损线。成交价、止损价和待突破价只放数据窗口。

## 时间和检查

使用indicator供手工观察，不等于真实账户下单。15分钟收盘生成原信号；后续突破使用前一收盘已知的价位。实时按当前报价检查触价，用varip记住已发生动作，避免重复入场；利润保护只在15分钟收盘更新。varip的持续行为见[TradingView变量文档](https://www.tradingview.com/pine-script-docs/language/variable-declarations/)。

历史15分钟OHLC不能还原盘中先后；同根入场和止损保守记止损。实时按收到的报价顺序处理，刷新后仅剩历史OHLC，模糊交易可能重建不同。不得声称历史标签代表准确逐笔成交、或用整根入场前的影线作为实时入场后止损依据。

另存每个版本，保留旧文件及改动记录；交付完整代码。能用直接变量和绘图解决时，不另造事件类型、多周期数据队列或复杂标签系统。自定义函数/方法必须有 `=>` 和缩进代码块；不使用`text`作为变量或字段名，内置`text=`参数不受此命名规则影响。静态检查不等于TradingView编译；未编译、未逐笔对照就明确说明。
