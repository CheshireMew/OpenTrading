## 具体原因

1. 实体突破确认只要求价格越过信号实体边缘。例如02:15信号实体上沿2412.27，下一根到2412.28即可入场；无需突破整根K线的最高价，更不要求突破后保持上涨。一次短暂上冲即可成交。
2. 同一方向持续满足条件不会不断开仓，但价格回到通道内再穿出，会形成新的信号。02:45收盘回到上沿以下，03:00再次穿出，允许03:15再次做多。当前规则没有“同一片价格区域连续止损后暂停”的限制。
3. 实际急涨急跌远大于1%止损距离。02:00整根高低差60.64，02:30高低差53.97，均超过开盘价的2%；1%止损距离约24。不能据此推断放宽止损一定改善总收益。
4. 2%利润保护没有启动：最初空单最高浮盈约1.26%，最后亏1%；07:30多单最高浮盈约1.71%，反向退出时仅赚0.63%。两笔都未满足当前保护启动条件。
