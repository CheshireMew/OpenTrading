只等下一根收盘：短时亏损单进一步降到300笔，胜率从27.34%提高到28.50%；但匹配的1749笔原止损交易中，119笔变成盈利、1115笔亏损扩大。平均收益变化为-0.0288个百分点。最差单笔是2022-06-15 UTC开出的空单，1064.39入场、1183.33退出，亏11.17%，退出发生在下一根15分钟收盘。这笔没有细周期数据回退或入场先后歧义。

只等下一根开盘及盘中：六年收益+36,328.44%，最近两年+597.13%优于原版+530.16%，但回撤31.60%大于原版29.05%。与止损区域限制合用，六年+48,730.66%，是改法中最高，但仍低于原版，最近两年也低于原版。

## 规则的具体定义

- 触及即止损：按原初始止损线处理跳空或盘中触及。
- 下一根开盘：第一根触及后继续持有；只在下一根开盘检查，仍越过止损线按开盘退出；收回则取消本次等待，之后再次触线可开始新一轮等待。
- 下一根开盘及盘中：第一根触及后继续持有；下一根开盘已越线则退出，否则盘中再次触线退出；整根未触线则取消等待。
- 下一根收盘：第一根触及后继续持有；下一根收盘仍越线，按该收盘退出；收回则取消等待。
- 所有“下一根”都指下一根实际15分钟K线。名义1%是判断线，并非延后退出的亏损上限。反向信号与已启动的利润保护照常退出，不等待初始止损确认。
- 区域限制：实际初始止损发生后先禁止当根重进，收盘固定该15分钟K线高低范围；后续收盘突破范围才产生一次新入场信号，再检查原确认与追价限制。区间不会跟随后续影线扩张；利润保护或反向退出不触发此限制。
