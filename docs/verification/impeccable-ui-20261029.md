# 界面优化验证记录

本轮使用本地 Impeccable 4.8.0，对已有界面进行精修。保留产品用途、业务计算、品牌、两套主题与已有研究入口；验收平台为 Windows。未变更后端、数据库结构、Pine 源码、交易规则或依赖版本。

## Git 基线

开始工作时执行 `git fetch origin main`，本地 `main` 与 `origin/main` 均为 `2096109`，领先和落后提交数都是 0，没有需要先推送的代码。原有未跟踪的 `.runtime/` 与 `docs/design/` 为运行资料、截图和 Logo 候选稿，未纳入本轮提交。

## 已完成的改动

- 将浅色和深色主题统一到共享的语义颜色变量，统一页面字体、控件、间距、边框、数字对齐、选区和可见键盘焦点；保持原有暖白墨绿与石墨青绿。
- 交易对搜索在窄屏下重新排布结果，补齐搜索及清空按钮名称，使用唯一弹窗标题标识，禁用不可选项并显示选中状态。
- 弹窗仅由最上层处理 Escape 和 Tab，排除隐藏控件；支持嵌套、初始焦点、卸载恢复和关闭后的焦点恢复。应用导航打开时，背景内容不可操作。
- 图表窄屏周期栏保留全部选项，自选列表改为可打开的抽屉；原生图表侧栏覆盖显示，不再把图表挤成细条。面板分隔条支持方向键调整，搜索、命名和兼容说明共用焦点管理。
- 修正 DCA 市场标签中的重复 `/USDT`，对齐配置字段，并提供计算中的禁用按钮和状态反馈。
- 完善市场、组合、研究、设置与数据健康界面的响应式、表单名称和页面标题；移除嵌套主内容区域。
- 分开加载编辑器和图表依赖，并独立放置共享预加载辅助代码，避免打开普通页面时提前下载整个 Monaco 编辑器。
- 从完成后的代码记录 `DESIGN.md` 与 `.impeccable/design.json`，便于后续保持一致。

## 验证

`npm --prefix frontend test`：28 项通过，包含新增的 4 项弹窗行为回归测试，覆盖隐藏及禁用控件、嵌套 Escape、滚动锁、焦点恢复和初始打开状态。

`npm --prefix frontend run build`：类型检查和生产构建通过。大型可选依赖仍会触发分包体积提示；未通过提高告警阈值隐藏提示。Monaco、Vela 和部分图表依赖按需加载，并在生产构建中实际打开图表与 Pine 编辑器验证。

生产构建通过本地预览服务与 API 运行。使用原预览数据库的独立副本，未操作用户的实际数据库或模型密钥。测试包含股票目录筛选与详情展开、DCA 默认 365 天模拟及三张结果图、搜索和导航的焦点恢复、嵌套弹窗、自选抽屉、面板键盘调整、主题切换和缩放后的图表绘制。

19 个非图表路由分别在 1024×800 深色、390×844 浅色下检查，共 38 项。主内容区和页面根节点未出现横向溢出，可见按钮及表单字段均有名称。范围包括四个市场页面、四个投资工具、设置、数据健康、八个研究入口和未找到页面。图表另在桌面及窄屏实际查看，稳定加载后的主图、成交量和 RSI 均可见。布局矩阵证明这些尺寸下的界面检查，不代表所有后台研究任务已重新执行。

Impeccable 执行了一次 `detect --json frontend/src`，原始报告含 11 条提示。涉及的字体及颜色用法已处理；条件表达式同时包含选中和未选中配色所产生的提示，改为共享分段控件样式，避免将互斥状态当成同一状态。保留原始报告，不把修改后的源码未经复扫称为“检测零问题”。

独立 Impeccable 完成评审逐张查看桌面深色、桌面浅色、窄屏搜索、图表及自选抽屉截图，并核对差异和规范，结论为 `ship`：本轮证据中未发现已确认的 P1/P2 回归或阻断问题。
