# PAXG：三个版本比较

原版：固定2%止损：+1.48%；盘中确认＋更快保护＋固定2%止损：+7.83%；盘中确认＋更快保护＋振幅止损：-45.81%。振幅止损降低了本次组合的累计收益。

1小时，EMA89，2020-09-25至2026-09-10；原版复用，仅新增两次。全仓复利，不计手续费滑点。

新组合都为第2或第3根盘中突破信号实体，每5分钟收盘更新保护、下一根生效。固定止损2%；振幅止损1.5W、限制0.5%—2%。仍浮盈2%启动，回吐50%。

旧版沿用1小时成交估计，新组合用5分钟核对成交，因此旧/新比较包含成交精度变化；两个新组合之间只有止损不同，可以直接判断止损的影响。没有单独拆分入场确认与保护各自贡献。
