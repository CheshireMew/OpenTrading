# ZEC：哪些改法有用，哪些没有

**本次有改善的是两种波动止损，以及更及时更新利润保护。整根突破、中心方向过滤和单次重进，没有提高七年累计收益。**

最后两组单独比较。+364.30%→+458.90%来自细化成交数据；+458.90%→+582.26%才是本次改变保护更新频率的比较。不能把两步一起算成保护规则的功劳。

突破整根信号K线没有改善：七年收益从+364.30%降到-78.01%，胜率从47.96%降到45.09%。交易减少，但平均每笔收益也转负。

顺过去6根中心线方向过滤，没有提高累计收益：+334.98%低于原版+364.30%。交易从4445笔减少到3912笔，胜率略升至48.54%，但不足以抵消减少的盈利机会。

1.5倍平滑振幅止损、限制0.5%至2%，累计收益+481.81%，胜率55.78%，最大回撤39.28%；三项都优于固定1%。平均初始止损1.48%，平均亏损单扩大到-1.33%；不是所有年份都改善，2026年至9月10日为-32.19%。本次未加固定1.48%对照，尚不能拆开随波动调整与平均放宽止损各自的作用。

1.5倍ATR14止损、限制0.5%至2%，累计收益+450.73%，胜率55.82%，最大回撤39.23%，优于固定1%原版；累计收益略低于平滑振幅版本。平均初始止损1.49%，不能据此认定ATR有独特优势。

止损后突破止损K线高低点、每个原信号最多重进一次，没有改善：累计收益-89.86%。实际重进1200笔，412笔赚、788笔亏，平均每笔-0.28%。重进还改变了后续可参与的交易，不能把它当作原版简单追加几笔交易。

同样使用5分钟行情核对成交，仅把保护更新从30分钟改为5分钟，累计收益从+458.90%升到+582.26%，胜率48.20%升到50.93%，最大回撤40.56%降到34.61%。利润保护退出却亏损从91笔降到29笔；平均盈利单从+1.14%缩到+1.05%，改善来自整体取舍，未做到每笔都赚更多。2026年至9月10日仍亏24.40%。

原版只细化成交数据，累计收益从+364.30%变为+458.90%，同根先后不明从252笔降到45笔；这属于成交估计变化，不能算作策略优化收益。122354根30分钟可匹配完整5分钟行情，300根回退原30分钟。全部8组原始突破信号一致，每笔确认时间、预先挂单价位和同一信号成交次数均通过核对。

## 解释和保留范围

波动止损平均约1.48%—1.49%，比原1%宽。它减少了止损次数，也让仍然失败的交易亏得更多。本轮结果支持保留这一候选，但没有证明改善必然来自波动适应，也不能从同一段已见历史证明未来有效。

更快保护并非逐笔实时执行：每根5分钟收盘才更新，下一根开始生效。300根细行情缺失或与30分钟不匹配的K线继续采用原30分钟处理；不匹配列表原样留档。最大回撤仍按30分钟收盘权益计算。

整根突破和重进分别有467、589笔同根成交先后不明，继续沿用原保守处理，因此否定的是本次具体规则与这套成交假设下的结果；本轮未擅自补跑细周期版本。
