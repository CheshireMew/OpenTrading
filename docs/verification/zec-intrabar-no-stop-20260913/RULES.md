# ZEC：盘中确认与取消固定止损，四组对照

用户先选择 EMA 通道而非另一类4小时动量策略，随后指出应选多年最高版本，并明确要求两个因素分别测试。尚未运行新回测时，范围据此修正为完整七年 EMA 通道冠军，原先最近两年 EMA55 的选择不再执行。

基准来自 cloud-timeframe-20260911 已保存的 full1 / ZEC / 30m / full：2019-09-10 00:00 UTC 至 2026-09-10 00:00 UTC。七年累计收益125.8631%；旧EMA55版本同七年15.6427%，最近两年1056.9674%。只在相同历史跨度的原通道版本里选原版；不混入4小时动量、年度收益或不足一年的滚动验证结果。

保持参数：EMA(高低中价,144)为中心；EMA(高低差,31)为W；收盘穿越中心±1.2W产生原信号；超过3W不追；固定初始止损1%；浮盈达到1%启动利润保护，允许回吐最高浮盈35%。原反向信号在收盘确认，下一根实际开盘平掉反向持仓。

四组：原版；只改盘中确认；只取消固定止损；两项一起改。无其他参数搜索。两种不设初始止损的版本仍保留利润保护和反向退出。

盘中确认沿用已检验的策略规则：信号K线算第1根，仅第2或第3根可成交；做多突破信号实体上沿，做空突破实体下沿；按0.01价格单位严格突破。事先用已收盘K线算出入场委托及3W追价上限，还需在对应内侧通道之外。下一根开盘越过触发价时按实际开盘成交，若开盘已超追价上限则该根不追。出现反向原信号取消旧等待；已成交信号只用一次，持同向仓不重复入场；不延后反向退出去等反向开仓确认。

取消固定止损指初始止损为None，不是关闭所有退出。利润保护依据持仓后的有利高低价在收盘更新，下一根生效，不把当前K线最终高低价用于提前提高当前保护价。有固定止损的盘中入场若同根先后不明，沿用先算入场再止损的保守假设并单独计数；本轮不扩展两种先后假设测试。

使用项目现有行情快照、模拟器、研究服务与worker。保留650根预热及原历史空档，不补造K线。每笔使用当时全部资金，盈亏滚入下一笔本金，不加杠杆，不计手续费和滑点。旧策略、旧结果不覆盖，原版须与旧记录的全部交易、信号、权益及汇总完全一致才运行比较。
