# ETH 六年历史第一名：Pine v1

文件：[eth_ema55_six_year_v1.pine](eth_ema55_six_year_v1.pine)。这是后来优化的通道策略，不是最初截图原作者的已确认源码。

| 项目 | 原回测参数 |
|---|---|
| 数据／周期 | Binance ETH/USDT，15分钟，普通K线 |
| 中心线 | `EMA((high+low)/2,55)` |
| 振幅 W | `EMA(high-low,31)`，**不是 ATR** |
| 做多门槛 | 中心线 + 0.4W，收盘从下方穿过才触发 |
| 做空门槛 | 中心线 − 0.4W，收盘从上方穿过才触发 |
| 不追价 | 沿突破方向离中心超过2W，不新开仓 |
| 初始止损 | 实际模拟开仓价的1% |
| 利润保护 | 最高浮盈达到2%启动，保留最高浮盈的50% |
| 反向信号 | 下一根开盘平掉旧方向；新方向不追价条件通过才反手 |

三个退出条件任一触发就退出：初始止损、利润保护、反向信号。没有固定止盈上限，也没有两根确认。已经持有同方向时不加仓；止损后等待下一次新的穿越信号，不能因为价格仍在线外就立即重进。

多单例子：100买入，初始止损99。某根K线最高到102，收盘后把保护价提高到101，从下一根开始有效；后来最高到110，保护价升到105。即使没有反向信号，触及保护价也退出。空单完全对称。这里不是“从最高价格回撤50%”，而是回吐已赚利润的一半。

## 使用

1. 在 TradingView 选择 `BINANCE:ETHUSDT` 和 **15分钟普通K线**。
2. 打开 Pine 编辑器，新建脚本，粘贴 `.pine` 文件的全部内容，添加到图表。
3. 保持默认参数；“限制历史日期”默认关闭，才能继续跟踪新行情。红线是最新初始止损价，橙线是利润保护价；右上角显示模拟持仓和价格。
4. 做多／做空标签标在确认信号的收盘K线上，成交箭头通常在下一根。按收盘信号决定，下一根执行；反向信号只平仓时显示“平仓”。
5. 创建策略提醒，选择 **订单成交和 alert() 函数调用**。入场及反向平仓由收盘提醒发出，保护单由模拟成交提醒发出；入场订单的成交提醒已关闭，避免同一入场收到两遍通知。订单消息保留 `{{strategy.order.alert_message}}`。修改参数后重新建立提醒，因为旧提醒保存的是创建时快照。

图中的持仓与保护价属于脚本模拟账户，**不是你的真实账户**。若你错过信号、从中途加入，或成交价不同，需要按自己的实际开仓价及开仓后的最高浮盈管理保护，不能照搬脚本已有仓位的价格。脚本不替你向交易所下单。

## 原成绩和对齐范围

原版本 ID：`c55_w31_t0p4_d2_a2_g50_s1`；项目运行：`4e65bfb4229646299932d76515ec0ac0`。

2020-09-10 至 2026-09-10，原项目累计收益 **+25,829.05%**；9,427笔，2,540赚、6,886亏、1笔持平，胜率 **26.94%**。每笔使用当时全部权益，盈亏计入下一笔，不计手续费和滑点。它是本会话这段ETH历史的最高结果，不是未来收益承诺。

本脚本保留进出场公式和默认参数，但不宣称 TradingView 会复现相同六年收益。两边的数据起点、K线缺口、价格精度、保证金模型及“跳空止损和反向单同时待执行”的处理可能不同。Pine 默认关闭保证金强平模拟，仓位仍按100%权益计算，以接近原项目的记账方式。

Pine 启用成交后重算，只用于按模拟成交价安装初始止损；成交回调不生成新的收盘信号，也不更新最高浮盈。最高浮盈用已收盘K线的最高／最低价更新，新保护线不能拿来追溯止损刚结束的同一根K线。保护价画在更新的收盘K线上，因此它代表后续生效的最新价，不表示该根早先已按此价止损。
