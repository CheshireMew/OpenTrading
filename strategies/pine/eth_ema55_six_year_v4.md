# ETH EMA55 四标签版 v4

完整代码：`eth_ema55_six_year_v4.pine`。旧版全部保留，只修改显示，交易规则及参数不变。

| 颜色 | 标签 | 时间与含义 |
|---|---|---|
| 红色 | 做多 | 收盘确认做多信号，下一根开盘执行 |
| 绿色 | 做空 | 收盘确认做空信号，下一根开盘执行 |
| 橙色 | 止损 | 初始止损或利润保护订单实际成交的K线 |
| 蓝色 | 平仓反向 | 因反向信号实际平掉原持仓的K线；距离过远时仅平仓，不一定反手 |

止损标签放在K线上方，反向平仓标签放在K线下方，增加间距与入场标签区分。标签高度用于排版，不代表成交价格。同根开仓后止损是原规则允许的，不隐藏这些交易。橙色标签也包括获利后的保护退出，不代表这笔一定亏钱。

中心线与通道恢复 v1 显示：EMA(hl2,55)，W=EMA(high-low,31)，突破线为中心±0.4W，外侧不追价边界为中心±2W。没有红色止损线或橙色保盈线。

替换原脚本后，在该策略设置→样式里关闭“图表上的交易 / Trades on chart”（若分别显示数量和信号标签子项，也关闭），保留自定义四种标签，避免原生箭头和成交数量再次重叠。

本地检查：v3与v4交易逻辑文本一致，新标签仅读取已成交记录；未操作浏览器，未做TradingView编译验证或新参数回测。
